# P05 A 实机 UI 实现验收合同

- 布局：逻辑视口 1280×800，地图 (0,46,1016,630)，12×8 格坐标起点 (52,60)、边长76，实际板 912×608；右侧纸面区 x=1020–1274，待命区 y=674–797。所有角点、路径、部署与视觉道具共用逻辑中心映射。960×600 仍应用 0.75 统一缩放。未用概念图作运行背景。
- 纸牌：暖象牙 #F5EBD6，墨蓝 #213D48，珊瑚橙 #AD4631 仅当前主要行动，禁止沿用旧暗底。概念图假数据全部替换成模型：状态为真实生命金币波次，角色 ATK、CD、RANGE；无角色 HP 字段。探索 6 金，直接返回唯一奖励；真实概率文字，跳过不扣钱。
- 底部9张待命卡兼容原持有上限；5 个部署。选中/匹配有高亮，所有合法格初始小标记，选中角色时显示可部署石台，已部署总有石台。保留切换路线、额外裂隙、召回、暂停、倍速、新局与重试。
- 右侧角色选中视图为真实头像与所选角色属性；遗物8枚图标与真实等级；出售需两次明确点击，第一次只记录目标 ID/等级，换选中、地图动作、清除、开波、重开、合并、召回、路线、暂停、倍速或探索均取消确认。第二次相同目标才调用模型出售。取消不扣金币，不更改模型。活跃局 Retry/New Run 第一次只记录操作身份（same/new），显式确认后重置；取消保持选择与模型，活跃战斗确认时暂停权威 tick 但不更改原暂停状态。无进度初始局及终局允许直接重开；重开提交后350ms防重复点击。地图按下只记录同格/按键，释放同一格同一按钮才提交，移动到另一格/越界/失焦/Esc均取消。
- 三关独立原画、入口/终点、平台、宝箱、遗物与角色为独立透明素材；LINEAR 滤波、按实际内容宽高限制角色屏幕尺寸。真正战斗伤害事件驱动动画，表演不更改逻辑。
- 验收：Godot headless实际回调与布局测试 35 项（开启/选中/确认/战斗/关卡/满待命/全部遗物详情、满级角色选择），出售确认测试 10 项，重开/地图按放交互测试 11 项，1280×800及960×600坐标变换/三关合法格合同共482项，全部通过。此为逻辑控件尺寸、回调与模型验证，不等于实际像素截图验收。此工作环境无 DISPLAY/Wayland/Xvfb，最终原生屏幕视觉与物理鼠标须另行验证。
