# P02 设计与开发验收契约

## 核心变化（相对于 P01）
由波后固定三选一升级，改为局内预算下的随机抽塔/抽核心、储备与部署、出售和二合一。玩家主要提升来自抽取核心和合成；塔的位置、阵容和风险路线仍然有影响。全部是局内虚拟金币，无真实货币购买或付费奖励。

| 项目 | 规则 |
|---|---|
| 开幕资金 | 24 |
| 塔抽取 | 6，三种塔等概率，新塔一星，独立随机 |
| 核心抽取 | 6，只抽未达到上限的核心，当场生效 |
| 合成 | 同种同星，二合一，最高三星；伤害系数 1/1.75/3.1 |
| 出售 | 一至三星塔回收 4/8/16；核心回收 4，降低一级效果 |
| 储备 | 总拥有量 9，上场量 5，部署与召回免费 |
| 波后 | 非最终波 12；第二关裂隙开启且无漏怪加 6 |
| 转场 | 召回已部署塔到储备区，保留所有核心与塔身份、星级；不重复返款 |

合成和出售只能转移固定的清算价值，不得创造额外金币。抽取使总清算值下降 2。预防经济软锁：尚无塔时不能耗光首塔资金，卖最后一座塔也留足替换资金。

## 战斗视角与技术
沿用 P01 验证的固定、正交、垂直 2D 俯视。所有机制共用网格、路径、塔和核心；俯视适合观察两条路线、多入口、射程及地形放大区。等距更具立体感但增加遮挡，横版不适合表达多入口，暂不更换。技术上仅延续 NGame 的固定步长逻辑/表现分离、无界面验证和独立验收，不移植任何玩法或资源。

## 开发验证（Godot 4.7.2）
- 价格、返款、升星伤害、身份唯一、储备和部署上限、非法和重复操作的原子拒绝。
- 抽取不允许直接指定塔型或核心；被拒绝的操作不应推进随机数。
- 同种全四塔开局由真实随机抽取产生，无需注入库存；种子 3（Pulse）、12（Burst）、78（Frost）均零漏怪通过第一波。
- 相同随机种子和操作重放完全一致。
- 种子 437，两种实际抽取、放置、消费策略完整获胜：
  - 场地优先，允许重复塔合成并开风险路：六波完成，Boss 击败，15 HP，0 漏怪。
  - 优先抽核心，保留较多低星塔，不开风险路：六波完成，Boss 击败，15 HP，0 漏怪。
- 风险路两波各新增 5/6 个真实敌人，主路数量不变，额外敌人生命是主路敌人的两倍；无漏怪时奖励 18，漏怪时仅奖励 12。
- 核心等级上限、跨波/跨地图所有权与核心持久化、最终胜利需 Boss 击败。

当前开发测试为 1398 项断言、零失败。测试中的隔离 fixture（提高测试专用金币或生命值）只验证边界、库存上限及漏怪奖励，不能冒充真实可玩通关；完整通关和开局试验均从 24 金币正常重置开始，无直接注入。

## 独立验收
对冻结源码另行验收，真实 GUI 检查 1280×800、960×600：抽取结果、消费金额、储备和部署状态、可合成及不能合成的反馈、出售确认逻辑、波后资金、跨关召回、风险提示和失败/重启路径。源代码、无界面或导出通过不等于真实浏览器/WebGL2/Windows 已通过，也不能证明长期平衡与趣味性。

此版本只检验抽取经济与三个战场变化的原型，不宣称商业级美术、音频、完整数值或内容量。
