# 原型设计与验收契约

## 1. 设计问题

在一局中连续遭遇不同的战场规则，玩家主要通过局内随机选择与协同成长解决难题，而不是通过局外积累或无限堆塔。不同关卡共享控制方式、塔种和战斗计算，避免拼成若干小游戏。

### 产品参考（机制研究，不复制表现）

| 参考 | 关键机制 | 本原型检验点 |
|---|---|---|
| [Emberward](https://store.steampowered.com/app/2459550/) | 拼接迷宫，塔位置与敌路互相约束 | 路径长度与覆盖取舍 |
| [Gnomes](https://store.steampowered.com/app/3133060/) | 回合间自由调整守卫 | 升级保留，重新布阵有意义 |
| [Everwarder](https://store.steampowered.com/app/2307170/) | 主动探索导致风险增加 | 开额外裂隙增加压力，同时获得成长 |
| [Wireworks](https://store.steampowered.com/app/4206270/) | 连接组件控制协同 | 地图机关与通用强化形成可见联系 |

## 2. 战斗摄影机判断

选择**固定、正交、垂直 2D 俯视**；逻辑坐标与图面坐标一致，地图同屏。

| 视角 | 优点 | 当前不选/选的原因 |
|---|---|---|
| 2D 正交俯视 | 可直接读路径、连线、射程、入口；点击与网格一一对应 | 最容易验证不同关卡机制。塔形、动作、标识必须足够清楚 |
| 2.5D 等距 | 地形立体感、建筑表现强 | 遮挡与深度排序妨碍射程和实际占位判断；后续可作为表现层实验 |
| 横版/侧视 | 冲锋、击中效果有辨识度 | 易弱化二维布局和多入口，难统一三类关卡 |
| 自由 3D 相机 | 表现灵活 | 相机操作会成为额外变量，拖慢首轮玩法验证 |

固定俯视不意味着最终美术必须扁平；后续可以增加塔高、投影、分层特效。但选择规则应始终与网格脚点保持对齐，避免视觉范围不等于实际范围。

参考引擎技术：[Godot 2D](https://docs.godotengine.org/en/latest/tutorials/2d/introduction_to_2d.html)，[Canvas layers](https://docs.godotengine.org/en/stable/tutorials/2d/canvas_layers.html)，[TileSets](https://docs.godotengine.org/en/stable/tutorials/2d/using_tilesets.html)。

## 3. 验收分层

### 开发验证（命令行可重复）
- 建造边界、防止重复占位、非法路径与花费、回收退款、塔上限。
- 确定性：相同 seed 和合法操作完全一致。
- 关卡规则：两条有效路线长度不同；额外裂隙在主路既有压力基础上新增敌人并带来明确奖励；共振机关与跨关保留的协同强化可叠加。
- 局内成长：不同塔种的强化偏好能给出至少两种胜利路径；在相同布局、同种子和规则的无强化对照中，结果应显著变差。
- 完整流程：建造、启动、战斗结束、选奖、转场、保留强化、最终胜负、重启。

### 独立验收（以冻结源码为准）
- 独立复跑测试、识别失败原因，把不符合契约的候选退回修改。不能把运行 import/export 成功当作游戏玩法验收。
- 真实视窗：1280×800、960×600 至少各一轮，活动路径和停用路径明显不同、塔卡与当前预算、有效范围、奖励描述、敌人数量、布局限制均清楚，按钮可点击并无边界裁切。
- 视觉反馈与趣味性的判断分别记录：无界面模拟可说明敌人、数值、范围、触发行为，但不能代替玩家操作和审美判断。

### 明确不在本轮
完整内容量、商业美术、音效、数值长期平衡、发行、长线账号/存档、NGame 玩法迁移。

## 4. 开发者实测记录

Godot 4.7.2，固定种子 437，自动脚本在每个建造阶段依据路径覆盖、塔射程、伤害和周期评分选择合法格。奖励按不同构筑的优先序选择，不预设必得某张卡。

| 对照 | 裂隙策略 | 结果 |
|---|---|---|
| Pulse + Frost；优先连锁、增伤、共振 | 开启 | 完成三关六波，Boss 击败，15 HP，0 漏怪 |
| Burst + Frost；优先爆裂、增伤、急速 | 关闭 | 完成三关六波，Boss 击败，15 HP，0 漏怪 |
| Pulse 对照：使用相同布局，每波奖励后清空强化 | 开启 | 第二关第二波失败，0 HP，15 漏怪 |
| Burst 对照：使用相同布局，每波奖励后清空强化 | 关闭 | 第三关第二波失败，0 HP，15 漏怪 |

范围：411 个开发者断言通过（包括两次 Pulse 重放完全一致、风险两波既有刷怪数量不变、额外奖励与等级上限、放大节点/共振区分、Boss 逃脱即使剩余 HP 大于零仍失败）。无强化对照是为隔离成长变量而设置的诊断条件，不是实际可选的游戏模式；不代表所有其他布局或种子都已完成平衡验证。
