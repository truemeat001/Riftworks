# P06 宝箱掉落表现
参考 Fortnite 的物件弹出、短暂展示、飞入背包的反馈思路，原创海洋风，不使用其资产。只花局内金币，无真钱。
- 0–320 ms：宝箱蓄势，环形进度与局部轻微震动。
- 320–870 ms：开盖、径向水光和粒子，实际角色肖像/遗物图标弹出并停留。
- 870–1350 ms：图标缩小飞入实际储备格或遗物格。
- 普通招募青色；新遗物紫色；遗物升至 R2+ 金色，明确文字 RELIC UPGRADED。现有游戏没有独立品质等级，不能把颜色当成虚构稀有度概率；未来品质机制应独立数值验证。
- 结果在开箱时立即由 Run.draw_loot 一次性结算，动画可免费跳过，不增加抽取次数、不改变现有概率，不使用假奖励或全屏闪光。
- 本轮暂未加入音频，不声称试听或真机验证完成。
