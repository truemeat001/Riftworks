# P08 机制实施与验收候选：碎冰潮（Shatter Tide）
## 冻结基线与唯一规则变化
- 基线 P07 Run.gd SHA256 `55f266962887b78956bc80542594ec337fe533d62c4deeee5b725888653dbf6e`，候选 P08 `438eb757a53d1c795ce7fc64910232f0c9f42f01a93379e572122c2f25eb2fa6`。
- 依玩法设计、数值设计审查规范，只比较一项组合机制；不开新池，不改探索成本、角色/遗物类别概率、售价、稀有度、奖励、路径、敌人HP/速度、R倍率、基础伤害、原有遗物效果及P07几何覆盖提示。
- 假设：潮雾织师持续施加 slow，礁锤护航员向缓速聚群触发原碎冰溅射；持有 Deep Frost 时，玩家可用集火目标的一部分剩余缓速换取周边未缓速敌方的分流控制。与铜鸣已有的缓速增伤联动存在选择；并不保证协调阵容一定赢，也不直接增加伤害。机制终审须由独立代理判断，与真实玩家体验分开。

## 精确顺序及边界
每个权威 tick 仍先生成、移动、衰减 slow、终点判定，再按原塔数组顺序攻击。修改仅在 Reef Hammer（kind 2）攻击内部：记录攻击开始时主目标（donor）的 post-move/pre-hit slow 值 S；原主伤、focus、原碎冰半径及次伤完全按原规则。完成本次实际 splash 命中及伤害之后，执行一次：
1. Deep Frost 遗物等级 L∈{1,2}，donor 必须是攻击前 slow>0 且攻击后仍存活的非 Boss。没有 L、slow 已到期、donor死亡或 Boss 均不执行。
2. 候选是本次真实次级溅射受击者中的存活、非 Boss、当时 slow≤0 对象；不可凭距离选未受击者，不覆盖已有 slow，不传播击杀残余状态。按离核心的剩余路径长度由短到长排序，同距按敌 spawn ID 升序稳定选择至多 L 个。
3. 若实际选出 n>0，令 d=(0.5×S)/n，每人设置 slow=d，donor 扣减 sum(d)，不执行额外攻击或递归传播。若没有实际受击合格对象，donor状态不变。状态-duration总量在该动作守恒；不同敌人的移速及控制位置不同，不能把duration守恒等同于减速路程、实际伤害或战术收益守恒。
4. 后续同 tick 的真实攻击读取更新后的状态；既有导电和碎冰规则、护甲/目标选择/死亡/结算不变。状态随固定 tick 正常衰减，动画不写战斗规则。

真实反馈独立事件列表 `game.tide_transfers`，每名实际 recipient 一条 `{from:Vector2,to:Vector2,duration:float,tick:int,tower_id:int,donor_id:int,recipient_id:int}`。生命周期阈值为当前tick−event.tick>10；reset/start清空。既有 `shots` 数量、伤害、synergy标签不增加，不把duration传播当新一次伤害。表现层按(tick,tower_id,donor_id,recipient_id)去重，不驱动伤害和RNG。遗物说明明确被分走的主目标控制时间，UI只能把传播称为缓速转移。

## 开发者配对实验（冻结候选）
实际 Godot 权威 API，固定 437–466 共30种子，五种策略 × 风险关闭/开启，P07/P08 各300局，合计600局。布局按真实角色范围及活动路径采样；两版本使用同一个策略、合法购买/出售/合并，策略随机数与游戏loot随机数隔离。脚本 `tests/p08_gameplay_matrix.gd` 是可复现完整实验入口（约数分钟）；可在独立工程中分别拷贝候选／历史Run.gd，不覆盖产品文件：`godot --headless --path <工程> --script res://tests/p08_gameplay_matrix.gd -- /tmp/结果.json`。支持没有 tide_transfers 的 P07 原版，字段为0。原始开发实验的两个版本分别运行，记录的实际结果如下。

| 策略 | 风险关 P07→P08 胜/30 | 风险开 P07→P08 胜/30 | 关/开实际传播次数 |
|---|---:|---:|---:|
| 满仓才合、逐角色总覆盖 | 12→12 | 6→6 | 71/23 |
| 超5角色才合、逐角色总覆盖 | 23→24 | 21→21 | 120/118 |
| 立即合、逐角色总覆盖 | 25→26 | 23→24 | 68/67 |
| 适应性混合（优先潮雾、覆盖重叠、有限出售） | 24→26 | 22→22 | 125/115 |
| 全合法格中随机站位，不合并 | 0→0 | 0→0 | 15/8 |

73/300候选局出现过真正转移，共730条实际接收事件；227/300**零转移配对**全部记录的游戏结果对象完全相同（排除候选附加计数键）。五个败→胜、无胜→败；具体 seed 442 在关闭风险下策略1/2/3改胜、开启风险下策略2改胜，452关闭风险策略3改胜。风险开启的活动配对中仍有生命值降低2及提高3的反例，不能称为全局无条件增益。每版本各波结算及战斗RNG约束：P07 1595波、P08 1594波，错误均0。数值差异可能通过风险奖励及未来抽取产生后续资产差异，因此配对同政策不是未来每波强制同资产。

该实验是开发者模型，不是独立验收。采样范围只是策略代理，不等于UI提示能保证赢；零散随机落位失败提示真实新手教学仍是重点。实际玩家能否理解 donor 控制时间取舍、愿否追求该构筑以及是否形成显著不同玩法，必须在独立验收及公开可用性测试继续观察。
