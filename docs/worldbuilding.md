# 裂潮驿站 / Riftworks — P03 世界观与角色美术设计

状态：P03 设计冻结方向。独立于 NGame，新世界、新角色、新素材；仅复用帧动画的工程经验。当前原型界面仍使用英文；下文中英名是本轮推荐映射，不要求同步实现全部叙事情节。

## 1. 从玩法反推世界

### 方向选择

| 候选主题 | 优势 | 取舍 |
|---|---|---|
| 裂潮驿站：浮陆与潮汐航路 | 路径、额外路线、增幅地形和抽取队伍的动机自然统一；航海角色与生物轮廓好辨认 | 必须避免做成写实海战或纯机械炮塔 |
| 梦境裁缝：修补裂开的梦 | 能表现奇异随机组合，角色可爱 | 缺少稳定的空间目标，敌我与路径的可读性较难保障 |
| 玻璃遗迹考古：遗物唤醒守卫 | 遗物组合的合理性强、晶体地形丰富 | 容易变成抽象晶块和建筑，再次弱化用户要求的角色化 |

选择第一种：用**经营一个会迁移的航路驿站**解释局内经济与跨关构筑，用世界的潮汐变化解释不同关卡。角色设定不应压过可读的塔防战斗。

### 一句话故事

世界曾由连续的航路连接。一场名叫“时间退潮”的灾变让大陆碎成漂浮群岛，旧航路被失序生灵占领。玩家掌管最后一座可迁移的裂潮驿站，召集来自不同浮陆的潮汐行者，沿断裂的航路修复三处中转锚点，抵达回声群礁。

- 玩家身份：驿站领航官。玩家是经营者，不是需要在画面中自己攻击的主角。
- 友方：潮汐行者（Tidewalkers）。具有职业形象、动作和个性，平时往来于驿站网络；战斗时守在指定锚位，以自己的武艺和工具驱散失序生灵。
- 敌方：裂潮生灵（Riftborn）。被时间潮汐卷入现实的生态与旅客；有明确身体结构和运动方式，不是移动光点。越深入群礁，能恢复轮廓的生灵越古老、越强。
- 主目标：保护航路信标（Waymark）。漏怪削弱航路稳定度；稳定度归零意味着驿站失去航道，需要重新出发。最终潮渊领主穿过信标代表封印中断，即使稳定度仍大于零也失败（现有 P02 规则）。

### 玩法与世界观一一映射

| 底层规则 | 世界观呈现 | 界面短词（英文） |
|---|---|---|
| 花金币独立随机抽取一位单位 | 支付约定契约费，开启一条未知来源的招募信号；立即有一位行者报到 | Recruit 6 |
| 抽取核心强化 | 打捞一件航海遗物；每件立即改变全队能力 | Salvage relic 6 |
| 不满意时出售 | 解除契约；成员回归驿站网络，返还保证金；遗物则转交驿站仓库换回航币 | Release / Sell relic |
| 相同职业、相同阶位合并 | 留下一位受训者，另一位成为其联合契约的支援导师并离开当前小队；受训者晋升，外观装备升级 | Train / Promote |
| 布阵、召回、跨关继承 | 备战期把行者派到锚位、撤回驿站；全员及所持遗物随驿站迁移 | Deploy / Recall |

不引入真实付费、抽取空结果、局外战力数值或三选一升级；货币仅为单局资源。不要用把有生命角色当道具卖掉、吞噬同伴的文案。现阶段不增加故事对话门槛。

## 2. 三个战斗区域

| 区域名 | English | 视觉主题 | 既有机制与戏剧冲突 |
|---|---|---|---|
| 折潮渡口 | Switchwake Crossing | 潮水退去后显露的木桥、褐金石板、海草，交叉航道地面保持平坦 | 驿站改变潮门方向，在长曲线和短密集路段之间权衡；玩家首次认识射程与位置 |
| 双潮裂湾 | Twinwake Cove | 青灰海、藻绿礁石、主航道与偏暖紫的裂隙航道 | 可主动接额外支线任务，敌人更厚、更密集；若阵容强项不在多路线覆盖，就有理由避险 |
| 回声群礁 | Echoreef Expanse | 石灰色岛礁、紫铜共鸣柱、暗海涌动，场景逐层逼近潮渊 | 角色的驻守位置获得增幅，遗物联动被放大；领主现身，检验单体伤害与控制，而不是只堆 AoE |

美术结构每关保持敌路、可驻守锚位和目标的视觉语法一致。不可驻守障碍用形状和纹理表示，不能只凭颜色。技能范围、路线和敌方脚底位置始终清楚。

## 3. 初始队员（不是建筑）

| 对应 P02 内部类型 | 角色名 | 行为与视觉轮廓 | 晋升变化示例 |
|---|---|---|---|
| Pulse | 铜鸣游击手 / Copper Scout | 长铜鸣枪、单侧软毡斗篷、风镜与细长身体；面朝目标举枪，主攻击是短促脉冲 | 进阶增添双肩护片、铜枪的共振节与脉冲装置，轮廓保持细长 |
| Frost | 潮雾织师 / Mist Weaver | 圆斗笠、编织雾丝的工具与潮壶，低重心圆润轮廓；抛雾丝造成减速 | 雾丝环、潮壶与衣摆层次增加，释放范围可见；避免被误认为纯治疗者 |
| Burst | 礁锤护航员 / Reef Guard | 宽肩、椭圆护盾、短柄重锤、结实的海船工装；锤击产生范围震荡 | 厚重护肩与锤头加固，锤击前摇更显眼；仍为人形，非固定炮台 |

统一角色美术语法：可辨认的头部、躯干、肢体、武器及站立姿态；不同类型不可只换颜色。友方轮廓优先于背景细节。未来可加入链路/生产/移动型行者，但不在本轮将未实现类型承诺为交付功能。

## 5. 画面与帧动画制作规范

**原创视觉基调：** 崩裂航海幻想、低饱和冷青灰的大底、暖陶赭木材、哑光铜件、偏灰帆布；避免 NGame 的北上旅团、灯誓符号与旧角色形象。建议初始调色锚点：环境深蓝灰 `#263d4b`、海草 `#557e74`、赭金木 `#ad8051`、友军高光青 `#82d9d3`、敌军珊瑚 `#d7685b`、增幅紫铜 `#b08acb`。所有受击红闪、状态环及敌路边界必须和底色拉开亮度差。

**镜头：** 保留 P02 正俯视正交 12×8 逻辑网格与无透视遮挡的点击。角色绘制轻微 3/4 斜俯视，统一视角，不用侧视大头像。角色脚底锚点为格中心，渲染可稍超格子边界；不要改逻辑位置或 AABB 碰撞来配合美术偏移。一般角色视觉边长目标 44–56px（64px 格）；大型敌人可超过格子，先保证点击提示、射程圈和脚底锚点可见。采用角色层按脚底 Y 排序；同 Y 用稳定 ID 排序。攻击与位移方向一致，左右镜像允许但异侧装备必须视觉合理。

**复用技术，不复用资产：** 使用 NGame 已验证过的逐帧图集+AABB 裁切打包流程，1px 边缘保护，记载原画布宽高、pivot、trim offset 与帧时长。能直接按统一元数据载入动画。先检查原始锚点，之后打包；运行时按偏移恢复每帧位置，避免头部/脚底抖动。英雄原尺寸不预设减半，若做尺寸压缩，应单独比较清晰度和文件大小。资源统一透明背景、原创角色、可重复打包。低分辨率像素美术使用最近邻采样；仅在视觉评审后选择是否开启其他滤波。

| 状态 | 建议首轮帧数 | 最低验收动作 |
|---|---:|---|
| Idle | 4 | 呼吸、衣摆或装备轻动，双脚原位 |
| Walk（敌方必需，友方未来移位可用） | 6–8 | 左右或多足完整交替支撑，不允许全程只挪同一只脚 |
| Attack（友方必需；Boss 依技能需要） | 6–8 | 预备、发力、释放、恢复清晰；动作命中点用事件元数据表达 |
| Hit | 2–3 | 一次明显短反馈，不用改变逻辑位置 |
| Death | 4–6 | 动作结束后淡出/沉入潮雾；不可用贴图消失提前结算影响战斗 |
| Promote（可选） | 4–6 | 进阶有明显装备变化；不是角色吞噬特效 |

动画演出不掌握伤害结算。逻辑固定时间步输出行动/命中事件，表现层选择帧状态；1x/2x、30/60/120FPS 下同种子同输入战斗状态相同。规则发生时刻不由绘制帧决定。阶段性验证：逐帧接触图、透明边缘、角色基线一致、镜像后的锚点、真实跑步交替与伤害正确、库存缩略图与实机角色一致。先验收一张角色联系表、一段实际走路和攻击，再批量扩展。

## 6. 世界观验收

1. 初次打开战场，玩家仅凭剪影可识别至少三种友方职责及三类不同敌体；敌我、脚底位置和路线清晰。
2. 关卡换地图后，角色与遗物身份、星级、钱流都保留；故事解释与 UI 真实规则一致。
3. 招募与解约文案不遮挡价格、概率和操作后果；不要求读背景才能开战。
4. 新角色与素材必须具有原创性，无旧 NGame 或 Slotbound 素材复用；保留生成提示和来源记录。
5. 工程验收须将自动动画数据/回调通过与真实屏幕移动、攻击及进阶画面验收分开。不以概念图或 headless 通过代替实际画面。
