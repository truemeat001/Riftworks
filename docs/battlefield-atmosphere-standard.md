# Riftworks 战场氛围设计与联合验收规范 v1.0
适用：场景美术、实时特效、音频、玩法和独立验收。依据 [美术规范](../DESIGN.md)、[交互规范](interaction-design.md)、[VFX规范](vfx-design-standard.md)、[序列帧规范](sequence-animation-standard.md)、[已确认玩法](gameplay-p04.md)。目标是表达变化而非增加噪声。P05 音频尚未接入，下述是 P06 候选设计，不声称已有实机功能。

## 1. 每次输入与协作约定
任务、关卡/镜头/目标、权威事件与位置、风格和声音参考、目标设备、预算。先定义玩家应感知的方向、规模、告急、战后痕迹，再分配三专业职责。场景给真实来向、可读路线及层次；VFX给局部事件；音频给时序与方向并让警报穿透混音。共同使用一个事件/状态表，不各自创造倒计时、威胁或伤害。缺失规则或性能预算标待确认。

## 2. 一句话目标：折潮渡口一波竖切
在固定俯视的微缩海岛上，玩家能从准备阶段潮声与裂隙涌流识别实际来敌方向，交战时从局部水雾/命中和灯塔危急提示看出哪里告急，胜败后从刚才战斗的礁岸/砂面痕迹辨认接战区。

已确认：P05 折潮渡口是固定 12×8 逻辑板，左右端为 Rift A 与灯塔，玩家在准备期间选择上下路线；点 Start Wave 才开始，无强制准备倒计时；一关2波、共3关；敌人移动、命中、慢速、死亡、漏怪、结束均以20Hz逻辑权威状态。此处真实来敌从左入口；第二关 Rift B 是否活跃以实际开关为准。本轮不新增玩法倒计时、伤害、修复、可反应技能窗口或大小镜头操作。危急定义作为表现规则建议：实际仍存活的敌人距终点≤2格（剩余路程，非直线距离）；不是新伤害规则，需验证阈值与提示重要性。若实际漏怪，再给受损反馈；无漏怪不制造损伤痕迹。

## 3. 阶段表
| 阶段 | 触发与结束 | 玩家应感受 | 画面（局部优先） | 声音（建议） |
|---|---|---|---|---|
| 静态准备 | 进入关卡、波次结束后准备；等待玩家开始 | 宁静但知道将从何处进攻 | 海面缓慢泛纹、旗帜微动，活跃裂隙轻微涌流/路径入口箭头；路线切换即时对应当前活动路径 | 低音量海浪与绳索环境循环；无紧迫倒计时，不用警报 |
| 波次将起 | Start 被规则接受至实际首个敌出现；若首怪同tick则立即进入交战 | 来敌方向、规模开始可感 | 仅活跃裂隙环/水花朝外、首批方向流纹；预告真实数量/角色；没有额外延迟或假怪 | 来向一声低沉海潮/木鼓，声像从真实入口位置；慢起战斗声床 |
| 首次接战 | 首次真实命中（权威 tick） | 火力接触位置与手感 | 命中点小砂尘/水星，真实源与目标短弧；首次接战短暂强化，后续以低量维持 | 局部敲击、冰晶、短风声；同事件聚合高频多命中，避免持续噪声 |
| 持续交战 | fight持续，目标/首批路径实际推进 | 压力方向、构筑发挥 | 按实际攻击与死亡区域累积视觉痕迹；冰雾/导电/碎冰采用实际状态，路径与血条优先 | 战斗声床按实际活动/密度少量动态增益，近端明确、远端低声量；不要用音量虚构敌数量 |
| 灯塔告急 | 建议：存活怪首次进入剩余2格且未被消灭；离开危险集合后解除 | 注意右终点、需要观察威胁 | 终点紧邻位置唯一珊瑚边缘闪/危急图标+文字；具体敌人可定位，触发短促，持续不频闪。真正漏怪时灯塔短受击并更新生命 | 独立短海钟音；duck普通战斗/音乐约3–6dB（建议，实测调整），150ms入/500ms退左右，报警间隔/去抖待测；伤害另有真实提示 |
| 波次收束 | 权威 phase 从fight到build/won/lost；立刻切换，不等待装饰 | 紧张释放，看到实绩 | 清除预警/命中/死亡残留；留下低对比砂面拖迹、冷却的冰晶或散小碎片对应真实接战区；真实结算数值和阶段 | 战斗声床0.3–0.6s淡出；真实胜/败短提示；海浪环境回归，不延迟操作 |
| 新波/换关/暂停 | 玩家主动连续Start；stage/reset、暂停/恢复 | 不卡住，可马上继续 | 新波前一波痕迹减淡并重置计数；换关/重开全部清除；暂停冻结模拟相关变化，保留必要状态 | 新波打断上一波收尾淡出；场景重置清旧音源；暂停选择冻结战斗cue，低环境声可保留但不冒充怪物推进；恢复重新衡量状态不重放旧事件 |

## 4. 最小制作清单（先验证一波，3项）
1. **来向**：场景复用 P05 portal、海面和真实活动路线；VFX新增低亮度海潮波纹/浪花层和入口短脉冲；音频先做一段可循环海浪和一声短潮汐提示（原创/明确许可，免费工具，不调用付费API服务）。位置来自实际当前path首点，路线切换或双入口更新，待机不假装开战。
2. **告急**：复用 lighthouse、真实敌人剩余路径距离与HP；增加终点警示轮廓+文字/真实漏怪伤害反馈，短音铃；高频碰撞声静音不影响视觉，状态解除立刻清警。建议音频总线 Master/Music/Ambience/Combat/Alert/UI，告急时用 Alert 优先控制 Combat 和 Music 的平滑音量，不需要引入 FMOD/Wwise/Dolby 中间件。
3. **战后痕迹**：依据已命中位置（shots实际to）和死亡位置/tick 建立装饰热区，建议每格累计有限命中，合并相邻、最多12处，每处低透明砂痕/碎壳/少量晶影，不把痕迹当新障碍或持续伤害。未接战的空地无痕。准备期保留至下一波进入前，之后淡出约1s；关卡切换/重开/失败清除。表现只订阅状态，不改seed、经济、伤害、路径与游戏规则。

音频例：Godot AudioStreamPlayer/AudioStreamPlayer2D、AudioServer Bus，路由独立、可渐变；web必须真实用户启动手势后播放，静音按钮有效，循环接缝、暂停、切后台恢复、资源装载与重置验证。当前无已确认音频资产/音效预算；预估值是设计建议，不是实测。素材来源、许可、命名、LFS与音频编解码验收后纳入项目。

## 5. 实际验收合同（待实现后执行）
同一版本、相同seed/输入、同一关开关氛围层 A/B，对测试者隐藏A/B名称；每次按「初始→操作→预期→实际结果」记录，用不用声音都应完成。不能把音频存在/特效数量当趣味性。
| 用例 | 操作条件 | 观察目标及预期 | 当前 |
|---|---|---|---|
| ATM01 方向 | 首关准备/上下切换；第二关可选B开启/关闭 | 无说明测试者可在第一只出现前指出实际来敌入口；关闭B不可发出B警报，准备无虚假倒计时 | 待验证 |
| ATM02 局部接触 | 选不同防御布局；相同实际命中 | VFX/声像局部反映接战点；能指出先接战位置，不用全场闪烁 | 待验证 |
| ATM03 告急 | 有存活敌进入建议阈值、随后击杀/漏怪；另无接敌威胁seed | 能在真实发生的同一位置识别紧张信号，解除后停止；无告急不误报、实际漏怪才有受损反馈 | 待验证 |
| ATM04 痕迹 | 两次不同站位，真实命中分布不同 | 战后能判断主要接战区，痕迹位置由事件佐证；下一波/重开/切关无残留假碰撞 | 待验证 |
| ATM05 静音 | 关闭Master/音乐，完整一波含实际告急 | 仍能理解方向、警报、状态和结算；玩家可随时取消/调整 | 待验证 |
| ATM06 性能/混音 | 1280×800/960×600，密集敌群、5塔、2x、连续启动、暂停切后台、弱GPU | 无爆音/持续叠加/多触发/遮挡重要UI；测机型、分辨率、实际frame-time p95/p99、active sounds/particle及透明覆盖；降级只删装饰，规则不变 | 待验证 |
实际审稿：时间点/位置｜玩家看到或听到的内容｜可复现具体问题｜影响｜修改建议｜复验结果；先修误警报和遮挡，再优化美术音色。

## 6. 当前 P05 审稿与待确认
P05 实际完整6波通关确认三关地图、路径、双路、状态、真实 0 漏，现有风格 A 方向通过；但背景基本静态，攻击主要短线，无真实动态环境音、战后事件痕迹；第三关增幅方块偏工程图。下一轮由场景美术负责海潮/痕迹素材，VFX负责绑定与遮罩，音频负责总线分层与短提示，三方共同用同一事件合同，独立验收。
待确认：告急2格阈值和冷却、低端设备/声量/性能预算、移动端、是否有镜头缩放（当前没有）、音频素材来源及授权、真实播放平台。只在权威玩法确认后扩大设计。
