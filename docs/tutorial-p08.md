- 15px逻辑引导正文、独立顶部入口，1280×800与960×600逻辑比例；不覆盖地图交互，不强制暂停、模态或额外支付。
- 提示点仅对 `coverage_preview()` 真实合法格比较所有活动路段的团队覆盖；只作为推荐，无额外战力、无胜率保证，其他合法格保持可用。
