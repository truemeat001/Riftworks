# 音效制作与验收规范 v1.0
适用：Riftworks；设计、制作、审查。沿用 `DESIGN.md`、战场氛围、特效、交互及玩法规范；只把真实事件映射到声音，不让音频反向控制游戏判定。

## 1. 参考及授权
每个事件先列参考：优先用户样音、项目已确认素材，否则每类 1–2 条可试听样音，注明声源、用途、借鉴的起音/材质/重量/衰减及是否已试听。无法试听标「参考待确认」。使用或改编现成素材时记录来源、作者、版本、许可证及使用限制，区分参考与实际使用；未经授权不得直接复制商业游戏音效。默认免费原创合成/录音，不购买素材、不上传未获许可原始资产。
- [BOOM Library · Casual UI](https://www.boomlibrary.com/blog/casual-ui/)：分层 UI 音效制作方法，参考待确认。
- [Pro Sound Effects · Footsteps](https://www.prosoundeffects.com/libraries/game-audio-collection-footsteps)：同材质、动作的独立样本与细节变体，参考待确认。商业素材未购买、未使用。
- [Davide Perico · Footsteps SFX Pack](https://davideperico.itch.io/footsteps-sfx-pack-68-footstep-sounds-for-games)：48 kHz/24-bit mono，17种表面各4变体的交付示范；付费素材，未购买、未使用。

## 2. 生成规格
每条事件记录：事件 ID｜声源｜动作｜材质｜力度｜距离/位置｜起音｜主体｜尾音｜目标时长｜循环｜变体数｜参考｜来源/授权。写清第一耳应听懂的玩家信息，避免把所有声音做成同样的提示音。
- 简单按钮及状态提示：合成短音；复杂奖励/命中：起音、主体、尾音逐层构建，分别保留源数据和控制参数。
- 脚步、纸、布优先录音或合法拟音素材；每个单次文件一个完整事件。高频事件先制作至少3个同材质、同重量的变体，音量一致、细节变化，避免重复播放机械感。
- 不以全屏巨响替代辨识度；关键告警优先于普通打击音/环境声。战场方向和距离仅在真实世界事件中映射；UI 非空间化。

## 3. 剪辑和混音
保留明确起音和自然尾巴，剪掉多余静音；同组对齐主观响度和力度，保留峰值余量和轻重差异，不把所有音频峰值强行拉齐。建议单轨峰值不超过 -3 dBFS（非听感通过阈值），混音峰值无削波。静音/没有输出设备时不得假称试听通过。
循环素材须完整循环段；检查首尾波形、零交叉或交叉淡化；连续试听至少3轮，观测接点爆音、空隙、响度跳变。立体声两声道的零交叉可能不一致，必要时使用短交叉淡化。来源：[Audacity 零交叉](https://manual.audacityteam.org/man/select_menu_at_zero_crossings.html)、[Audacity 交叉淡化](https://manual.audacityteam.org/man/creating_a_crossfade.html)。

## 4. 文件与接入
- 原始交付：48 kHz、24-bit PCM WAV；点声源单声道，真正需要空间感的环境背景使用立体声。
- 命名：`sfx_<action>_<material_or_result>_<nn>.wav`，`ambience_<scene>_loop.wav`。变体逐条导出。素材库规模增大可参考 [UCS 分类](https://universalcategorysystem.com/)。
- 保存声源/生成参数/随机种子、原始 WAV、事件清单及授权记录。Godot 导入/运行时副本与母版分离；如引擎对24-bit PCM不支持，保留母版并生成经验证的16-bit播放副本，不覆盖母版；Web 首次播放必须来自玩家有效输入，静音/音量控制与后台恢复需实测。
- Master/SFX/UI/Ambience/Music 独立音量；峰值并发限制按平台测得。高频战斗音用受控复音及变体，关键预警优先保留；跳过、取消、场景重置停止属于该事件的尾音。
- 新增音频资产按仓库 LFS 策略保存；禁止提交悬空LFS指针，禁止未经确认产生费用。

## 6. 可复现验收与交付
1. 检查文件可解码、采样率/位深/声道/时长、样本数、峰值、NaN/异常静音，记录实际结果；格式通过不等于听感通过。
2. 单独试听、并排比较同类变体、正常与峰值并发实机试听；检查噪声、爆点、刺耳、削波、尾音、重复触发、事件对齐；循环3轮以上。
3. 实机：固定种子7，连续4箱（真结果：普通角色、普通角色、新遗物、等级提升）；三类应有可区分反馈。点击跳过不扣币、尾音停止；失败/余额不足无奖励音，关闭音效不改变结果或随机数。Web首次手势、重连/前后台切换测试。
4. 交付事件｜文件名｜参考/授权｜实际时长/格式｜循环｜制作方法/参数｜试听/实机结果｜待修项。缺音标待生成；没听标待试听；没测试标待验证。参考、制作、验收三者分别记录，不用合成参数冒充实际听感。
