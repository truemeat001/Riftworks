## 2. 主循环及权威合同
1. 准备阶段探索入口展示真实费用 6 个局内金币、当前池和条件概率；不足、池空、战斗时明确不可抽原因。
2. 同一按钮释放一次 => 以 Run.draw_loot 原始函数结算一次，立即扣费、更新仓位/遗物阶位、真实 last_loot 与 RNG；结果保存不可变快照，绘制与音频只消费该快照。金额与仓位立即可见，不伪造加载/未到账状态，也不把演出说成决定结果的过程。
3. 宝箱短暂从右侧展示区切到地图中部的潮汐交付台。视觉大幅提升，不影响 HUD、金币/生命、仓位、实际概率、Skip 和 Start 可见性。因地图被遮罩，地图手势明确只关闭演出，不隔着展示台落子，演出台持续可见英文文案 “SKIP FREE · Click map to skip”。已到部署教学步骤也只提示可跳过、演出完成后部署，不用高亮被遮挡的合法格诱导错误点击。
4. 锁扣解除、容器改变为对应已取得结果的真实材料与轮廓，开盖，唯一实物或牌面弹出，停留可读后飞至真实仓位/遗物格；飞行只是视觉，已到账。若真实对象已经被明确操作改变（卖掉、合成、部署等）则先结束演出，不再绘制虚构目标。
5. 等待自然结束或任何时候免费跳过，保留当前选择；持久结果摘要仍可查看类别、实际 rank、名字、效果（空间不足则单行摘要+现有详细选中面板或 Tooltip，绝不把效果硬截掉）。下一次明确点击探索才再次扣费 6，原概率保持。

## 3. 冻结时间轴（60Hz示意，实际时间插值）
既有 P09 总演出 1.35 s。冻结普通 1.35 s、新遗物 1.60 s、升阶 1.85 s，额外时间用于稳定阅读实际效果，不增加开锁等待；同一开头 .00–.52，任意时刻立即免费跳过。统一不可变 RevealPlan（tier、duration、material=.12、open=.32、result=.34、flight、arrive、end），由已经提交的 kind/rank 唯一映射。Main、Overlay 与 GameAudio 都消费同一个 plan，不独立写散常量。原 `LOOT_DURATION` 作为普通兼容常量，运行时活跃条件改为 plan.duration，_skip_reveal 将当前时钟设到 plan.end，不能用 max 1.85 锁住普通；旧测试按每个结果的真实时长断言，不能删安全检查。

## 4. 输入／取消／无障碍状态表

|---|---|---|

| 有真实结果、正在演出 | 显示已到账与免费 Skip，两处可见控制；HUD保留 | 再点 Explore 仅免费 Skip；绝不在同一事件上继续消费。后续新的一次明确点击才抽。键盘 Esc **仅结束演出并保留选择**，之后单独 Esc 才清选择；Explore/Skip 的鼠标和键盘按下也冻结本次意图，不能按下时是免费Skip、跨过自然结束后释放变成付费Explore |
| 地图被覆盖 | 按下曾发生在演出期间时，明确的跳过专用手势锁直到释放；取消/拖出/失焦清锁 | 同格有效释放只跳演出，不部署、不选塔、不收回；即使演出在按住期间已自然结束，也不能让释放穿透地图。本次点击在非演出阶段重新开始才按原逻辑部署 |

| 不可抽 / 拒绝 | 原原因与金钱/库存不变，无宝箱/奖励声音，只原 reject cue；持久旧收据标 “LAST REWARD / 上次奖励”，不可将其当成本次新到账 | 不启动演出；回归正常准备 |

- 输入实现合同：捕获物理按下时的 intent（PAID_DRAW / FREE_SKIP / NOOP），只接受匹配的非取消释放；一个指针/键盘激活 token 同一时刻有效，消费后即失效，拖出/失焦/取消/重启清除。鼠标、Enter、Space 和触控模拟分别测试，拒绝 Key echo 与混合输入双触发。辅助功能若直接提交单个激活动作则按该原子动作入口判定，绝不顺带再执行一笔。现有 P09 的 pressed 时读取 loot_age 不足以满足跨自然完结边界；需真实控件 down/release 路径验收，不能只调方法证明。
- 1280×800 和 960×600 实机主要内容不遮住顶部金币生命、右侧真实概率和免费 Skip、底部仓位与 Start；标题不少于20逻辑px，类别/rank 18–20，名字24，效果14–16（960约10.5–12像素须实际看清），深色海图底＋浅象牙文字；长名字/效果最多2行，禁止缩小至不可读。中央卡非 UI button，信息层避免让玩家误以为要再点击确认领奖。
- 读屏：原 P09 自绘 CanvasItem 不能假称已支持读屏。正式实现建议在真实 HUD 的可访问控件提供实物类别/rank/name、效果与按钮明确标签（如“Skip animation; reward already received”）；非编码前独立人工验证 Windows NVDA/支持的浏览器读屏可达性列为未验，不以普通 Label 或 CanvasItem 判定可朗读。若项目目标含移动触屏，另做明确 Escape/Skip 触控热区与系统取消。
- 减动偏好：免费跳过始终可用。可选无演出模式只有在明确用户配置需求时加入；不必须增加全局设置开关。避免连续闪屏，整个 stage dim 静止而非来回闪动。
