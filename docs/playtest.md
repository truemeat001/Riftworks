# P03 实机试玩与修正

Godot 4.7.2 Linux 图形窗口，1280×800，种子 437，通过真实鼠标招募、部署、升阶、随机遗物、开启双潮风险、跨关重新部署、增幅地形和最终首领。六波全部完成，剩余 15 HP、漏怪 0。两倍速用于减少等待，仍运行实际战斗。

初次全局试玩发现：上一波最后一次射线冻结在准备阶段，换地图甚至留在错误地形上；结算仍显示下一波。修正为仅战斗阶段绘制射线、非战斗清空攻击表现时钟、使用战斗逻辑 attack_tick 与 tower_id 触发动作，终局显示结算，并在最终波准备阶段提示 Boss 逃逸直接失败。修正后真实图形窗口重新招募与通过第一波，确认准备阶段残留射线消失。逻辑冻结 hash 未改变。

体验判断：一套构筑确实可跨三关完整跑通，射程/增幅/状态可见；角色初步可辨，怪群密集时重叠，角色仍偏小，成长/合成视觉反馈弱，抽取揭示和战场场景仍是占位表现；一次通关不能证明难度适用于真实玩家。原型没有完整受击/死亡动画状态机、带前后摇的事件时间轴或四方向行走。这些为后续明确改良项。
