## 1. 优先级与 1:1 定义

1:1 要求的是已批准设计的**实际交互画面结构、主要对象成像、材质/色调/光影/比例、动态状态与设计意图**高度对应，不能用一张合成整屏图假装运行时 HUD。概念图的假数值、虚构内容和示意路线不属于必须照抄的内容。地图网格、路径和机制必须以冻结 Run.gd 权威状态为准。

- **P0（阻断）**：真实规则、可操作、动态 UI、可辨识地图和实际画面不一致、误扣、错误出售、关键控件裁剪、地图坐标/对象位置不一致；任何一项失败禁止写“1:1验收通过”。
- **P1（必须修复或明确记录偏差）**：结构比例、A 的纸面和海岛手绘质感、角色/光向/剪影、切图和字体、大小比例、颜色清晰度及按钮状态一致性。单色 token 或自动逻辑测试不等于美术1:1。
- **P2（偏好）**：纸面颗粒密度、边缘罗盘、浪花、装饰数量及微调；不应盖住 P0/P1。

## 3. 像素审计与视觉审稿

截图只作为真实运行状态证据。独立脚本在固定归一化区域报告色调比例供审稿：A 顶部纸/暖色约63%，右栏约74%，底栏约65%，地图暖沙约43%、海蓝/青28%、近黑2%。阈值是可解释的风格回归报警，不是自动宣称复刻成功：

- 顶/右/底 HUD 应由暖米象牙纸面主导（各暖色比例目标 ≥50/55/50%，近黑像素 ≤12%）；空闲右栏中段须有安静内容纸面，正文背后不能是喧宾纹理。A 右栏空白纸样 RGB约(242,231,215)，与 DESIGN.md #F5EBD6接近。
- 战场具分层浅海/暖沙陆地；海青≥15%、暖沙≥20%、近黑≤12%为一般报警。真实占位、高亮、战斗特效使比例变化合理；不能涂平纯色来满足阈值。
- 主操作源 token #AD4631 / #FFF8EB；选中 #176D72 / 白；正文 #213D48 / #F5EBD6；次要墨色 #546568。WCAG 正文对比≥4.5:1，图标/边界≥3:1，以真实合成图像为准，不只检查配置。用捕获的按钮中心背景/文字及纸面空白采样验证，图标32/48px在实际960还能识别，不仅靠颜色区分。
- 与 A 并排审查五个视觉重点：1) 海洋自然浅滩/礁石/栈桥/入口灯塔；2) 大块面非像素手绘微缩角色，友方三种职业依靠武器/帽/盾辨识，敌方普通/快速/重甲/Boss轮廓明确；3) 宝箱青灰/绳索/暖木，不是P04金属像素箱；4) 暖象牙纸面、深墨文字、珊瑚CTA；5) 局部装饰和光照方向一致，角色脚底阴影不遮挡路径/文字。每项标通过/偏差、截图证据、具体像素或位置，不用总分掩盖主结构不符。
- 人物视觉比例应与A有同等可读性，普通友方可见高度大致80–116px（含武器，实际格76，可稍越格），常规怪物约50–90，Boss 100+；容差由当前图集源比例与拥挤状态决定。实际检查相邻格、同一敌道4+敌人、最上/下排、左右朝向；脚部逻辑锚定，Y排序合理，最大武器动作/死亡帧不会遮挡HUD。动画用本轮实际角色资产逐帧构造，不能把旧P04像素静帧放大冒充 A 手绘。

## 4. 真实数据与交互验收不可省略

A 显示 20 生命、96金币、角色HP220、SELL+24 与示意卡片数；这些是概念示意，**不是真实实现需求**。P04冻结规则：初始15HP、24金币，统一付6航币，首两次随机角色，同池随后70/30，基础角色/遗物出售4、Rank2 8、Rank3 16，最多5部署、9拥有，8遗物。没有塔HP规则，不造假。因此 A 数字与实际不同应记录为正确偏差。

## 5. 最终证据矩阵

必须在冻结哈希下取得同份实机构建实际截图，注明 seed、波次、资产状态、屏幕尺寸：

1. 初始无角色，观察探索概率及开始禁用；1280×800和960×600。
2. 开箱弹出时（0.2–0.42秒）与结果归位，呈现真实对象及余额变化；与 A 的亮色宝箱/纸面比较。
3. 计划态：至少三名不同塔、至少一名敌角色的实际关卡预报，选中不同角色；满9仓位、全部遗物可查；截图至少一张真实出售确认/合成选择。
4. 战斗态：实际第一/中期/密集敌人、至少2种怪物和3种角色的不同剪影，显示真实路径、冰雾/攻击/死亡；至少一段实际GUI录屏或连续截图。
5. 区域切换/末波/终局，所有按钮状态正确；保留三阶段真实机制/入口、终点及12×8。
6. 运行独立 callback state test、逻辑原始Run hash校验（若改规则须全回归并跑 P04对应矩阵）、图集AABB/anchor/alpha、截图色调分析。主agent物理点击必须另作真实验收，不能把headless称试玩。

## 6. 追加 UXR07 及同格释放门禁（interaction-design.md v1.0）

- P0：活跃局（资产、金币、波次或 tick 已变化）点 Retry/New Run 只显示不可逆进度损失警告和绑定模式 `same`/`new`；切换另一模式仅切待确认。只有再次点同模式提交；提交后 0.35s 内额外点击不重置/不生成额外 seed。无进度初始态和终局可直接重开。
