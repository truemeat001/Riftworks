# P07 序列帧、美术、VFX 与战场氛围联合审查

对照 P06 冻结的《DESIGN》《序列帧动画设计与验收规范》《特效设计、制作与审查规范》《战场氛围设计与联合验收规范》。用户已确认 P05 的航海手绘微缩方向；本轮**不替换已通过方向审查的角色和海图素材**，仅将真实战斗事件转化为局部环境线索、状态形状和更明确的攻击反馈。不存在新玩法、伤害、强制倒计时或虚假可躲避技能窗口。

## 一、审稿发现与实际整改

## 二、实际实现与接入

独立模块 src/BattleAtmosphere.gd（RefCounted），不修改 Run.gd、随机种子、抽取、敌人、塔位、任何伤害或经济字段。所有状态可回收、不使用每帧新材质/节点；当前接入使用 CanvasItem 简单矢量图形而非高密度粒子。与手绘场景组合时需以实机观感复验，不能把程序图形等同新发布级美术。

- reset(game)：明确关闭危险并清空所有痕迹、冲击、历史事件。防御性检测权威 tick 或总漏怪计数回退；正常重开仍应明确调用。
- observe(game)：仅在接受 Start 和每一次 Run.step 后调用。返回本次观察边沿 wave_start、first_contact、alert_enter、alert_exit、leak_count、wave_end，附 grid entry/contact_pos/danger_pos/core_pos/tick。重复同tick观察不重复记痕、不重发音频。
- active_routes(game)：实际当前活跃入口列表；remaining_threats(game)：按真实剩余路径距离排序的存活危险敌。
- draw_ground(canvas,game,origin,tile,idle_seconds)：实际入口、战斗痕迹、持续冰晶；在路径/入口后、单位前。
- draw_combat(canvas,game,origin,tile)：实际冲击，单位后、敌血条前；原细线停止重复绘制。
- draw_alert(canvas,game,origin,tile,font)：只在实际战斗中的真实告急/漏怪反馈，位置来自当前 path 最后点。主界面将该提示层放在血条之后、HUD之前，避免被角色遮挡。终场UI仍由权威 phase/HP 负责，最后一帧立即转入 build/lost 时不保留旧红环。
- draw_rank(canvas,position,rank)：真实阶位低干扰标识；draw_amplifier(canvas,pos,active)：显式地图增幅对象外观。

主界面波末明确清除 death_fx，保证过场和备战没有旧死亡动作。当前 Run 的 shot 字段未带唯一事件 tick/target_id；权威 tower.attack_tick 与当前 shots.life 连接：主命中初始.16经0.05tick后=.11，次级.12后=.07，旧主命中≤.06。仅处理 attack_tick==本次 tick 且 life>.065 的记录；如果未来增加显式 shot.tick，优先该字段。适配当前冻结规则，不把渲染帧当伤害事件，也不将同一动作的各命中误当多个奖励。阶段变化时不把刚离开的旧地图命中记为新地图痕迹。

### 生命周期与性能边界

| 对象 | 来源 | 期限/取消 | 上限 |
|---|---|---|---:|
| 入口动势 | 当前活跃路径 | 备战低强调无倒计时；开波短强化10 tick | 2入口 |
| 首次接战强化 | 首个权威新 shot | 6 tick | 单波1次 |
| 普攻命中与联动 | 权威 shot.to，from、synergy | 6 tick，战斗结束即清 | 28局部效果 |
| 持续冰晶 | alive && slow>0 | 状态终止、死亡、换关 | 实际存活敌 |
| 灯塔告急 | remaining_distance≤2 && hp>0 | 危险集合为空、phase!=fight 停警 | 1个标签/单核心 |
| 真实漏怪 | run_leaks 增量 | 最多8 tick或结束波次 | 1个脉冲 |
| 战后痕迹 | shot.to/death.pos | 同地图备战保留；下一波20tick淡出；切关、重开、失败清除 | 12处当前，12处旧波淡出 |

所有 fight 时间由 tick_count 推进，暂停不推进、2x 只加快权威 tick；准备时入口轻微呼吸使用外部 idle_seconds，且 Main 冻结暂停。危险声由音频组复用 danger_active 和实际 danger_pos；攻击/击杀声仍由真事件绑定，未让视觉回写 Rule。音频从实际路径入口声像触发；不要把 UI 出现次数作为声音结算次数。

    godot --headless --path . --script res://tests/atmosphere_tests.gd

- ATM01 首关实际上下路线切换、B关闭仅1真实入口、B开2不同真实路径，准备无首接战或告急边沿；
- ATM02 配置真实 Run 生成、抽取、部署、开波，逐权威tick观察；实际首接战一次且位置等于真实 shots.to；每次观察前后快照核对全部读取模型字段和 RNG state，零变化；重复观察不复制效果；
- ATM03 剩余路径与直线距离反例（近终点但实际剩余路程>2，无告急），恰好剩余2格触发，死亡解除，多个真实 threat 按最近剩余距离排序。实际 Run.step 的临近终点漏怪夹具造成真实HP-1、run_leaks+1、一个 leak_count 边沿，绝不形成虚假受击砂痕；
- ATM04 同地图实际已发生接战的下一波淡出；合成多事件夹具检验12痕迹/28影响上限、重复观察去重、寿命与切关/失败/重开清理。
- 覆盖机制而非替代整局实机：特别明确“近终点距离反例”和“密集多击点”采用标注的合成数据夹具，实际 Run.tick、首次命中和漏怪各通过真实逻辑调用。

## 四、待整体验收的场景与不确定性

1. 原生或真实 WebGL2 1280×800/960×600：先波入口方向、跨波B开/关、首次真实接战、告急入/出、漏怪、同阶段战后痕迹。实际游戏截图/录像应观察安静度、攻击层和血条优先、临近核心的标签是否遮挡单位/路径。关闭音频仍可观察告急与胜败。
2. 30/60/120渲染节奏、2x、长帧、连续切关/重开；真实高并发 draw calls、帧时 p95/p99、显存和实际 GPU 透明过绘待测，不能用28上限或136帧图集面积推断60fps达成。
3. 若波次最后一击立即结束，权威流程直接回备战，旧瞬态攻击和告急不强行保留；真实结算及可保留的同关痕迹提供证据。最后一次正常漏怪恰好结束波次时不显示战斗红环，HP与结果仍真实。这是明确的表现边界，不伪称全事件都至少显示一个屏幕帧。
4. 视觉化方向和告急采用当前模型实际数据；阈值2格与玩家能否第一眼理解、实际战场提醒是否与音频合适，需要独立盲 A/B；自动断言不证明玩家感知质量。
