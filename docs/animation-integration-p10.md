- Guard and Boss old RGB art and frame durations are exact; `register_roles.py` uses manually identified crop-relative near eye/eyelid landmark, registered to idle body axis. Small vertical 2px source-space bob, 3px hurt lift and 12px death settling are intentional. Every mirrored source crop is bit-checked against original; mirrored offset reflects around authoring anchor. No new frame count or payload for those two actors. No claim that manual points prove every foot is planted or that their motions are final. 960×600 measurements scale by 0.75.
- Crab uses unchanged P10 32-sample atlas and original `CrabGait.gd`, distance phase driven by true Run positions. Hurt preserves running pose and a short red/ivory tint for 0.16s instead of snapping to old frame. Death stores the exact last live phase/facing and uses the same new asset, gentle bottom-anchored compression (24% y / 5% x) and dimming, then fades in 0.45 simulation seconds. No generated old-style death image. First death frame at age 0 uses exact sprite/raw hue; last frame has fade. Face is retained on vertical segments to avoid sudden mirroring.
- Death events observed after each true fixed tick; deduplicate same tick. Persist on same stage even when phase changes to build/won; snapshot death anchor & scale BEFORE layout cache invalidates on wave advance. New wave/restart clears. Death age advances at current presentation speed, freezing if paused or restart confirm open. The actual gameplay victory/loot/state changes immediately; last boss dying visual continues in old board with victory visible, no economic or input wait. Stage-advance death is intentionally suppressed rather than misdrawn on a different board. Two such events remain a transition-design follow-up (not falsely passed). Stage-transition completion is separate from same-map death visual; could design small explicit old-sector recap later, never stale hit region.
