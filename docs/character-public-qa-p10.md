# Riftworks P10 角色动作公开测试独立验收（P09 冻结基线 + P10 Crab 候选）
**结论：不放行公开测试。** P09 不只是潮蟹走路不自然：珊瑚甲怪、首领同属锚点跳变，三名友方统一存在攻击发生与动作峰值错序，波末最后一个死亡动画被清空（包含首领）。P10 的 32 帧潮蟹跑步候选是正确修复方向，但不能直接替换跑步图后仍用旧受击/死亡，未做跨状态整合的候选不得算成正式通过。其余角色视觉验证必须继续，不可用 690 局规则模拟代替真机审美和可读性。

## 3. 真实6波事件证据：缺陷严重性与修复约束

### P1-A：不变壳体跳动及方向、受击切换

| 同向水平run连续步进 | 样本数 | 全身质心向后 | 最差前向位移 | 最大权威向前位移 |
|---|---:|---:|---:|---:|
| Crab | 2979 | 596 (20.0%) | -14.87px | 5.43px |
| Sail | 500 | 0 | 无逆向 | 8.15px |
| Coralback | 895 | 178 (19.9%) | -8.98px | 4.08px |
| Boss | 61 | 11 (18.0%) | -18.82px | 4.18px |

复现：seed437按 trace 合法阵容，观看前三类波及最后首领；固定锚点表逐帧对照（同一壳体非仅接触腿）。原版绝大多数异常发生切帧；拥挤缩放只是表现层变量。设计规范最初仅以底部不透明10%取接点，脚的交替会误移动身体；首领同样取错参考点。渲染镜像以 `dir.x<0`，垂直路线默认朝右、未保存前一有效方向；当前seed实际只横向正方向和垂直，因此没有虚报左右转向已过。每次改形/转向应明确方向保持，不可跳向无意义方向。

修复：复用 P10 crab 固定壳体/按实际前进距离推进相位的手法，为 Coralback 和 Boss 制作一致层身份、同腿支撑相位、双骨骼等；先锁身体轴及支撑接触，再做逐帧位移和实际尺寸复验。可用明确标签轨迹先测所有角色，不能靠统一质心移动整个PNG“校正”而让脚滑。Boss重点要保证冠/壳/眼睛稳定、重量感强，慢速重踏可自然不同于小蟹；Sail Ray单独锁定眼/身体稳定轴，用鳍振和有意周期浮动表达，勿强套脚步阈值。保存每方向姿势和固定参考点；转弯时使用最后 meaningful x 或制作专有转向，并检验轨迹连续。同一模型状态/种子每个显示帧不得改伤害逻辑。

复验：真实 x1/x2/慢速、暂停恢复，3轮连续循环，左/右及转弯、密集8波。v1.1 螃蟹建议身体横向残差 ≤1px/逻辑tick、同腿连续支撑 ≤1.5px/tick；Coralback/Boss调整上限应先以动作设计明确有意重踏/后仰而非遮盖问题。任何放宽都记录具体接点、复现场景。所有新壳体在 run/hurt/death 同一参考点（死亡有明确倒地帧位移），不突然换类型。正常速度独立盲 A/B，1–5自然度/节奏/脚步/方向/辨识度逐项≥4，而非只用量化指标。

### P1-B：三友方攻击动作与真实命中错序

复现：`Run.gd` 587–629：真实攻击 tick K 立即产生 attack_tick，伤害/死亡或减速当步确定，创建 life=0.16 的主shot，当tick减20Hz的0.05，即仅剩0.11s；`Main.gd` 185/1225–1228：同tick渲染 attack clip 从第1帧（idle原姿）开始，18 fps，第2/3帧为举起预备，第4帧才是挥击峰值。实际20Hz采样：K+0/+1/+2/+3/+4=0/0/1/2/3帧（零起索引）。峰值最早 K+4=0.20s，主shot 最迟 K+2仍有0.01s，K+3时消失。等于先看到掉血/特效，再看到举武器，最后才挥击；Hammer地面火花晚于真实目标命中。独立 339 次合法攻击（Brass174、Mist69、Hammer96）；所有有shot的最大寿命0.11s。6波本次实测最短攻击间隔分别14/17/28 ticks，无过快截断实测证据；不能把极端高攻速候选当已复现。当前源设计三名角色共同机制缺陷，而不是所有339次录屏均人工逐帧观察。

修复建议：维持权威伤害/冷却/护卫截获/链击不变，订立“事件脉冲驱动动画”契约：
1. 真实 damage_tick K 是唯一真值。如继续即时伤害，K同tick（≤1逻辑tick的呈现误差）必须进入真正释放/击地关键姿势，清晰弹道发射/光束和命中反馈同一事件，不能让 atlas 的空闲预备发生在命中后再挥击；设计准备姿势可由经确认可发射的模型信息提前预备，但不能错误承诺目标或把表现预备重新写入伤害。
2. 弹道视觉清晰，区别弹道（Brass电/链）、雾弹/减速（Mist）、击地冲击/范围波（Hammer）；确保目标点用实际真实轨迹及截获后的 guard/chain/多目标，不把本应命中A的表现画向B。即时伤害采用近乎即时的命中反馈和视觉轨迹消退，不能产生明显“子弹尚未到却死了”；若设计真正可见飞行时间，应在模型规则受控迭代中引入独立发射和命中时刻，再回归数值/护卫及全部随机种子，不能靠表现晚播伪造时序。
3. 攻击释放后短促回收，后续攻击不可因视觉clip未完成而丢失、错重复事件。暂停后冻结战斗相关演出，原始 K 对 x1/x2 同一逻辑tick。按 LOD/并发仅减辅助层，不减正确信息。
4. 检测事件日志与实际原生录屏：每个塔id和attack_tick 唯一、弹道起点和真实目的点、命中反馈时间、伤害与死亡时间对应；x1/x2、30/60/120 FPS；首发、近/远、目标被护卫拦截、多目标链、敌人死亡、密集高攻速、暂停后恢复。观察正常速度看清“发射-命中-回位”，不得反复播放预备导致角色像抽风。
5. 纯表现修复的逻辑对照必须相同seed/输入逐tick完全一致：伤害、HP、冷却、护卫数据、经济、通关结果。修改前记录旧版攻击峰值延迟200ms，修改后按实际渲染帧检查峰值相差≤50ms（建议门槛），画面可辨和方向匹配为独立人工观察门槛。

### P1-C：波末死亡被同tick清空，受击反复重置

`Main._process` 795–817 死亡效果age按渲染 wall delta 增量，并且 stage 切换和 phase结束即 clear；真实6波共81死亡（normal53、runner16、guard11、boss1），实测模型最后死亡分布 [(wave0,tick152,normal),(1,342,normal),(2,616,guard),(3,933,guard),(4,1173,normal),(5,1526,boss)]。这些6个必然没有完整death显示，其中Boss是奖励关键。已看原生胜利截图只有空场与结算，不足以独立证明所有死亡播放，但结合精确源码可判定同tick清空。倍速下 run/hurt/attack 由模拟ticks推进，death按实时时长.45且在restart confirm非paused时继续老化，表现冻结策略不一致。首领死亡要为玩家交代视觉结果，不能瞬间消失。

受击：每次 hit_tick 更新直接使 hurt 开头重新出现（没有独立节奏）；本次304段连续hurt（normal188、runner41、guard63、boss12），36/304只有第0帧，最长分别15/7/13/12 tick（高于目标.16s）。零帧段也可能由死亡/离场截短，不能全部算卡死；持续长段可由连击重置导致动作冻结/频闪，需实际观察。新蟹若仅替换 run 则在这频率下大量闪回旧身份，必须同时处理。

修复：受击尽量保留距离驱动步态和当前一致身份，以短促 tint/姿势叠层传达命中（同一tick多击可聚合但关键反馈保留）；死亡优先保留当前位置/面向/比例，完整明确倒地/消散，之后回收。波末模型结算不延迟，表现允许独立非常短的死亡收尾层（同地图），状态转换取消旧地图实体，跨关使用清晰总结反馈而不留鬼影。首领明确胜利死亡过渡并行于结算，不添加玩家操作阻塞。统一 battle visual clock 与 pause/restart-confirm/2x，清理旧事件/暂停恢复不补播洪峰。复验：记录实际最后敌人/Boss完整可见帧、结算/重开/切关、同一主体伤害时刻和死亡位置，至少检查 x1/x2 和暂停/返回；真实截图/录屏证明非单帧。

## 4. P10 潮蟹新rig候选

根据隔离实验 `animation/rigged/rig-production-review.md`，32样本来自同一6条腿两骨骼、8相位关键设计，非随机重绘；8样本单体 normal 30/135、slow42/42同腿支撑间隔超1.5px；32样本单体正常/慢速177/177达标，拥挤811/813达标（2次超上限，max1.81），上壳代理漂移.878px；用户已认可新动画视觉方向。8帧不能因keyframe看起来不错而当成最终支撑足检测过关。32帧是优先集成候选，但仍有两项拥挤边界以及run/hurt/death旧图闪回必须解决；转向/整体原生完整8波仍未验收。现有离线replay用户可看效果，但不冒称原生或真机通过。修复后三类甲壳敌人统一方案并记录每个图集/帧表/脚接点、实际容量；源Rig保留可再生性。

## 5. 制作人整改优先级和最终门禁

- P1 先分派并行：动画美术（Crab/Coralback/Boss一致rig与受击死亡 + 友方释放/回位关键帧），技术美术/工程（distance/turn/hold/attack-event-clock、终局死亡生命周期；与VFX Agent共同准确目标与同步），独立视觉QA复验上述合同，制作人只在证据通过后签核。保留Sail/Mist稳定造型及已有规则，不大规模无依据重做全部素材。
- 本报告实际确认的项目：原版7角色全部状态逐帧、两尺寸离线正常速度3s时间表、精确镜像68/68、真实合法6波headless trace、真实原生截图可辨。明确失败不是只是未确认：三个甲壳敌人同类漂移；攻击时间映射；波末死亡。
- 必须补齐：完整整合版八波 native+可用WebGL2浏览器；实际 960 与1280 resize、左右/转向、连续3轮正常/慢速/2x、暂停/恢复，全部角色攻击/受击/死亡逐事件录屏、实际战斗同屏叠加可读性，密集后景遮挡、低频刷新和长 frame，帧率对照；新旧盲A/B独立评分，同一规范各项≥4，无P1遗漏，保存版本/平台/初始输入/截图或录屏/实际结果。模拟结果、截图、离线动图及美术完成都不能单独宣布该门禁通过；真实玩家测试可在内部候选通过后开展，不伪造人类评分。
