# P10 Atlas exact deduplication experiment
Baseline P09 tight AABB + 2 px extrusion packing includes duplicate held poses and exact mirrored directions. P09 136 frame references occupy 2048×2006 (15.67 MiB RGBA8 theoretical), 68/68 left/right pairs mirror exactly. Crab-32 separate candidate 64 refs, 32/32 exact mirror pairs.
Algorithm: canonicalize full RGBA padded sprite by SHA256 of direct/mirrored pixels, collision-check bytes, stable shelf try widths 256–2048, preserve every frame's original offset, state, timing and directional semantics. Each frame now has its own rect + flip_x. Full padded reconstruction is bit-exact:
- P09 136/136, 40 unique padded images, 1344×872, 4,687,872 RGBA bytes vs 16,433,152 (−71.5% theoretical), PNG 1,683,396 vs 4,410,604 (−61.8%), padded utilization 88.06%.
- Crab32 64/64, 32 unique padded images, 1344×484, 2,601,984 RGBA bytes vs 5,476,352 (−52.5%), PNG 639,695 vs 1,193,662 (−46.4%), padded utilization 94.40%.
These are isolated offline exact-byte comparisons, not GPU VRAM, runtime frame time, final package, or production integration claims. Runtime must interpret flip_x while retaining original destination anchor and dimensions. After renderer implementation compare actual rendered pixels with the original atlas (both facings, seam, ghost alpha, texture filtering), then native/Web export size and real frame timings. Candidate assets must not replace production atlas until this gate passes.

## Native proof (Godot 4.7.2 OpenGL3)
Real native renderer two SubViewports 1280×1600, all 136 frames including face-left and ghost alpha at fractional .28/.45 scales. Original vs canonicalized texture with explicit destination-preserving flip transform: 316,424 nontransparent pixels, 440 pixels differ (0.139%), max channel difference 6/255, mean absolute 0.0007, zero pixels >8. Not bit-exact GPU rasterization: tiny interpolation/rounding differences; source padded pixels exact. Observed native frame board consistent.
