## 真实计算
- `coverage_current()`：活动线路列表，每条含 `id, length, covered, fraction`。第二关不开附加裂隙时不列 extra；第一关只列当前选中的路径。
- `coverage_preview(cell,kind,rank,ignore_id)`：返回 `valid, reason, lanes`；每条活动线路含 `id, length, unit_covered, team_before, team_after, delta`，单位为逻辑格长度。传角色 ID 时身份、职业及阶位必须匹配；非法部署/战斗期/越界、路径或其他占位均返回原因且不变更状态。
- `coverage_merge_preview(id_a,id_b)`：同形返回值，精确遵循已实现的合成身份、升阶和落位规则。第一角色在场保留原格，否则继承在场第二角色的格；两者均在仓则无场上覆盖变化。必须比较实际消费角色后的团队覆盖，不只是赢家单角色射程。
- 合法部署或合成的候选布局为临时数组，不写原角色字典。relay 的存在条件用候选布局重算全队（移动/消耗的角色可能改变邻居射程），第三关 amp 与 rank/range 遗物以真实射程公式重算。

对于每条有方向的路径段 A→B，长度 L，单位向量 u，每个射程圆心 C 计算投影 p=(C−A)·u、垂距平方 q=|(C−A)−p·u|²。若 r²>q，得到在段上的闭区间 [max(0,p−sqrt(r²−q)), min(L,p+sqrt(r²−q))]，无长度/相切不累加。排序并合并所有圆的区间，取并集长度；段逐一累加。重叠覆盖不会重复计数，活动线路分别展示，终点共享点不重复提供虚假线长。移动可能产生负 delta，需如实展示。

这是几何射程覆盖，**不是 DPS、击杀率、伤害时间、通关预测或最优自动布阵**。它忽略移速、缓速、攻击间隔、过量伤害、目标抢占、范围溅射、穿越时间和个体加成等因素。即使 100% 覆盖也可能失败。
