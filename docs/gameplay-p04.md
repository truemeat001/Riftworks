# Riftworks P04：统一随机补给、角色连携与分路防守

状态：P04 冻结设计契约与开发调参结果。沿用 P03 的角色世界观《裂潮驿站》、稳定回合制经济和独立模拟架构；P03 冻结版本不修改。数值以本轮最终冻结的代码及独立验收数据为准。

## 1. 本轮体验目标

P03 已经证明随机招募加合成有多种胜利路线，但玩家仍能主动指定“抽角色”或“抽遗物”，随机结果关联较弱；两路地图又存在长时间共同覆盖的尾段。P04 重点把随机资产、阵容联动和布防问题统一成一个闭环，而非追加稀有概率或更多数值型按钮。

**一键打开局内补给 → 拿到一个未知角色/遗物 → 通过站位、连携、升星、出售构筑 → 为当前敌人类型和路径做准备 → 开战 → 获得新补给。**

设计灵感取 Fortnite 等战利品游戏的“未知补给物揭晓、拿到以后调整战术”的节奏，不复制外部产品的 UI、资产或商业化系统。没有真实付费、现金兑现、可交易价值、博彩式空抽或付费重抽；随机仅是关卡内有限资源的玩法约束。

## 2. 统一随机池

一个按钮、一笔价格（6 航币）、一个结果，取消可指定类别的两个抽取入口以及一切三选一。抽取后立即结算到仓库（新角色一星，遗物直接升阶），以后可回收或合成。

| 项目 | 初始契约 |
|---|---|
| 开局资金 | 24，四次补给消费 |
| 正常情况 | 70% 角色 / 30% 遗物；角色类别内三种等概率，遗物类别内所有未满级类型等概率 |
| 开局保护 | 在拥有角色数小于 2 时只开放角色类别，保证最少两个独立随机职业、不固定职业组合；在 UI 实时显示原因和概率，非隐藏保底 |
| 角色容量 | 总拥有 9，场上最多 5，角色类别满时仅抽遗物 |
| 遗物满级 | 该遗物退出当前候选；全部达到上限时仅抽角色 |
| 无可用候选 / 资金不足 / 战斗中 | 拒绝，不扣航币，不推进 RNG |
| 出售回收 | 一/二/三星角色回 4/8/16；遗物一阶回 4 |
| 合成与跨关 | 二合一同职业同星，最高三星；跨关保留 ID、等级、遗物、金币 |
| 波后收益 | 非最终波 12；第二关主动开放支线、零漏怪额外 6 |

正常无容量限制时，三种角色各占 23.333…%；八种遗物均未满时，各占 3.75%。随着容量和遗物状态变化，类别内实际概率随可用池变化；不能显示与执行不同的概率。抽中类别后在该类别候选中等权选取。开局保证两个角色，剩余两笔独立抽取使最终 2/3/4 角色的概率分别为 9%/42%/49%，仍全部随机；不存在一开局抽完四次仅有一个角色的情况。保护逻辑也适用于后续主动合成或出售导致持有不足，出售每次产生确定性成本，不可凭此无限攒金币。

生产接口为 `draw_loot() -> Dictionary`，成功返回实际揭晓结果；`reward_odds() -> Dictionary` 是只读动态概率。禁止通过 UI 或其他正式入口绕过统一池指定类别。若开发测试需要按类别构造 fixture，使用测试隔离方法并标注其不能冒充真实随机通关。固定同 seed 与同动作序列应完全重现；被拒绝的操作不改变下一次有效抽取。停止/跳过揭晓动画不影响结果。

## 3. 结果反馈：未知、揭晓、决策

抽取结果即时生效，UI 可以做短促的补给箱或遗物打捞揭晓，但不以接近大奖、虚构滚动结果、长时间等待或概率误导吸引反复消费。建议：

- 点击补给按钮首先确认余额扣减，同时显示一个真实结果的角色大图/遗物图标与名称。
- 在 0.2–0.4 秒内揭晓真实结果（完整动效建议不超过 0.9 秒、可跳过）；连点时不允许重复扣费、异步覆盖或者丢失结果。新角色自动选中，玩家可立即部署。
- 角色揭晓显示当前星级、可相同职业合成、核心作用或可立即用的联动。回收确认显示确切回收值（6 花费→4 返还），强调策略取舍。
- 箱子动画、金币、音效、稀有旧称不能脱离实际概率；若无稀有度系统，所有物品以角色职责/遗物类别表现差异，不伪造稀有等级。

## 4. 三角色协同

P03 有 Pulse 铜鸣游击手、Frost 潮雾织师、Burst 礁锤护航员；当前强化更多依赖各自星级与核心。P04 新增直接依赖另一角色的作用，而不是单纯同角色重复部署。

| 条件 | 联动规则 | 战术价值 |
|---|---|---|
| 潮雾织师命中 | 正常减速（继承持续时间与核心、星级规则），同时成为其他角色可识别的“潮雾标记”状态 | 即使抽到多个织师，也可控制两条路；状态消失即失去联动 |
| 铜鸣游击手命中当前减速目标 | 单次主目标伤害 ×1.20 | 织师置于较前，铜鸣后继输出；快怪可被两者处理 |
| 礁锤护航员命中当前减速目标 | 此次爆炸半径 +0.35 格，溅射伤害倍率 ×1.10 | 引导玩家利用减速形成密集队列，扩大覆盖 |
| 无减速目标、减速到期 | 沿用基础攻击与核心/星级效果，无联动倍率 | 避免无条件同质化伤害膨胀 |

协同只作用于当前命中自身，不能凭借 UI 动画延迟或 FPS 改变伤害。连锁的二次目标不应额外触发不可控递归。明确联动的计算顺序、预报和动画反馈；若守卫或 Boss 已有抗控规则，其减速持续/速率沿用原定义，但只要状态层仍有效就可享受相应联动。应收集每种联动触发次数、额外伤害、实际控制时间与对应角色参与情况，避免只看总胜率。

后续可探索更丰富的角色关系（例如同一路资源生产、远程增幅锚位），但 P04 不引入预先锁定职业流派或大量未经验证的元素克制。

## 5. 关卡目标与布局

保留三关每关两波的最小实验长度。不同地图要求同一阵容换打法，而不是只有背景或平均 HP 变化。

| 关卡 | 主要压力 | 期望玩家行为 |
|---|---|---|
| 折潮渡口 | 单路、可切换长短航线；第二波加入快怪 | 学会补给、角色站位和控制；同价阵容可不同布局 |
| 双潮裂湾 | 第二条额外高风险路线，主支路在大部分移动距离上相互分离，接近目标才汇合 | 评估阵容是否有足够分路覆盖，而非所有角色集中在共享长走廊；房间风险收益是主动选择 |
| 回声群礁 | 共鸣礁石临近角色增幅；混合怪与领主 | 集中利用联动和地形增幅，仍需避免漏怪；必要时卖掉或转职构筑 |

P03 主支路存在长公共尾段。P04 双路分别沿 y1/y6 进入，保持主要活动段分离、不共享长尾段。冻结代码主路 (0,1)→(8,1)→(8,2)→(11,2)→(11,4)，长 14 格；额外 (0,6)→(8,6)→(8,5)→(11,5)→(11,4)，长 13 格，仅在共同终点相接。开关额外路线不改变主路角色、数量、属性和航线。实际实现路径需经画面验收与独立覆盖测试。

数值以 P03 冻结值 [22,36,66,96,165,198] / Boss 1150 为起点，开发实测后 P04 冻结为基础 HP [22,38,66,96,180,215] / Boss 1275，升星倍率仍 1/2.15/4.6。风险额外怪仍为 2× 基础 HP，主路混合正常、快速 0.6×HP/1.5×速、重型 1.6×HP/0.75×速。第一波维持 22 HP，避免加重早期最多两个角色的合法抽取压力；中后期吸收连携增长，双路的 2× 风险机制保留。

## 6. 验收与设计终点

1. **经济与概率**：首两次角色保证、正常 70/30 分类概率、各类别内等权、容量变化与满级排除、完整经济守恒、失败不推进 RNG、实测 3000+ seed 首次有两角色后的分类分布，拒绝的第三方选择入口。开局最坏两个角色+两个遗物的合法种子至少三种同职业阵容能过第一波，无伪造抽取；不保证不做部署或过早开战的玩家能赢。
2. **真实随机模拟**：固定至少 18 个（建议 30）种子，无直接指定类别的实际 draw；低信息随机消费、场上优先、顺应融合、保留两/三职业协同、出售追指定职业、开关风险等策略同 seed 对照。记录有效抽取率、出售净损、阵容成型时机、联动触发、每波核心血量、Boss 剩余血量和失败阶段。调参目标是多个策略有明显胜利路径，不是统一高胜率。
3. **协同机制**：控制状态有效和到期分别验证 Pulse 主伤害 1.2× 与 Burst 范围/溅射倍率，损伤不受画面 FPS/暂停或倍速影响。角色相关核心的通用保底仍应起作用。比较同价单职业与多职业阵容在快怪、重甲、分路上的优劣；不能所有场景都只需一个最强职业。
4. **空间机制**：实际核算主/支路长度、共享路段、开关是否改变主路线；在相同阵容和钱下比较集中与分路部署，至少存在分路更优的有效局面。风险应出现真实漏怪与收益拒绝，不能开风险全种子无代价支配；也应有可以获得奖励的可重复策略。
5. **实际操作验收**：使用真实游戏画面，从点击补给、查看结果、部署、出售、合成、开战到转场完整操作。确认不显示 3 选 1、只一个付费抽取入口、概率和剩余资金正确、揭晓可跳过、角色动画清晰且协同反馈对应真实命中。若环境无法启动 GUI，仅记逻辑、回调与布局通过，不称已真人试玩。
6. **体验边界**：纯随机不是故意制造经济死局，乐趣来自根据随机资产形成构筑、改变站位与策略，而不是靠大量重复追稀有物；实际用户试玩前不宣称玩法已成熟。


## 7. 冻结开发证据（非独立实机试玩）

源文件 `Run.gd` SHA-256：`7f623075e85a6f4f8ce898c9622c75f0d605694be1a5c114b06570088bd2e0e0`。开发方对同一 18 种子 × 6 决策策略 × 支线开/关执行 216 局实际战斗 API 模拟。冻结版新增表现死亡事件后，按相同矩阵重新执行，结果一致；无直接注入资产：

| 决策策略 | 关闭裂隙 | 主动开启裂隙 |
|---|---:|---:|
| 尽量满场、超过5只才合成 | 16/18 | 15/18 |
| 立即合成同种同星角色 | 16/18 | 16/18 |
| 角色不足3时尝试回收遗物，之后满场 | 15/18 | 14/18 |
| 尝试出售过量重复角色 | 16/18 | 15/18 |
| 强追单一初始角色，主动出售异类 | 12/18 | 8/18 |
| 随机落位、无合成 | 0/18 | 0/18 |

奖励 1180 波次核算无差错，风险航线额外奖励 60 次、漏怪后拒绝 113 次。第一/第四策略因回收条件未有效改变动作而在测试种子中等价，不应夸大为完全不同构筑；合成与满场两个策略存在不同实际配置，均可获胜。强追同型比顺势利用更难，符合“结果价值覆盖优先”的设计方向。随机落位策略不能直接代表真实新手；下一轮应增加路径覆盖引导及首次合成提示，再测试阅读界面后会做基本决策的玩家模型与真实操作。额外初步模拟给随机落位加入合成规则后，关闭风险胜 7/18、打开风险胜 1/18，说明单一规则提示有实质价值，但不是对人类玩家获胜率的证明。

开局极端抽取实测：已按真实付费抽取筛选出“恰好两个同职业角色 + 两件遗物”的 15 个种子（每职业五个：铜鸣 1/19/85/211/352；潮雾 56/80/149/174/452；礁锤 87/181/230/387/394）。使用按射程覆盖路径的部署策略，15/15 均完成前两波，剩余 15 HP。这验证了透明两角色保护的最低合法资产可用性，不代表随意站位都能过关。
