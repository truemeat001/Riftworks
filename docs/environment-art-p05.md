# P05 环境、宝箱、遗物资产交付

## 方向与来源

用户批准的概念 A（`Riftworks-art-research/Riftworks-P05-concept-A.png`）是风格参照。所有新 PNG 由内置 ImageGen 原创生成，非截取概念 UI、非竞品素材，也不沿用 P04/P03 像素纹理。以暖象牙砂洲、海盐蓝浅水、岩石层次、绳索木桥、珊瑚与左上柔光统一画面。后处理仅按真实 alpha 裁切、等比采样与透明留白，不改变绘画内容；三个背景保持原文件。

生成集合：
- Tidecross 初稿：连续平地与外圈岩岸，作为备选已在 `Riftworks-art-research/Riftworks-P05-tidecross-environment-initial.png` 归档（不参与运行）。主 Agent 评审指出缺乏 A 的多层岛架与水湾，第二稿增加不规则砂洲、沿外缘凹入浅湾、两座木码头、船、帐篷和岩层；主 Agent 已批准换入运行目录。
- Twinwake：双侧窄湾与珊瑚/盐岩，两条路周边保持清楚；Echo Reef：较古老的灰紫色层状石灰岩与天然矿脉、盐绳和贝壳。均为独立新图，不是简单换色。
- Chest：引用 A 右上物件的木质/贝壳/绳索语言，两幅独立姿态（闭、开）同尺度、相似轮廓；开态盖子上扬，正面基础不跳。
- Portal、Lighthouse：引用 A 的入口暖灰石拱、蓝色潮汐旋流、暖象牙灯塔与珊瑚橙屋顶；生成分隔双物件后按 alpha 裁切。只作为模型入口/目标位置的画面层。
- Deployment pad：独立浅圆形手绘石块底座，留白顶面，不烘焙单位、职业、坐标或网格；运行时赋予真实可部署格状态。
- Relic medallions：独立 4×2 透明源图，逐格按 alpha 裁切为 128×128。顺序与 ID 一致：`power`闪电、`rapid`双箭头、`range`罗盘、`chain`双环、`freeze`雪晶、`blast`珊瑚、`focus`金瞳、`relay`双浪。没有虚构的稀有度边框或数字。

## 运行与地形几何契约

地图源图为 1585×992 RGB；UI 的实际显示区域是 `MAP_RECT=Rect2(0,46,1016,630)`。逻辑坐标保持 P04 的 12×8，`BOARD=Rect2(52,60,912,608)`，`TILE=76`。格心坐标按 `(52 + (x+0.5)*76, 60 + (y+0.5)*76)` 计算。背景图有浅水与石岸装饰，**不是碰撞图**。背景不包含路线、格、部署、敌人、假入口目标或文字；所有这些可交互元素按真实 `Run.gd` 数据动态绘制。图中的水/岩石位置不得自行封锁格子。准备态有效位置可显示提示点，选中可部署角色时真实合法格展示石座，已部署持续石座；用户操作所需的场上状态保持可辨识。需实机检查靠边水上/岩石上的石座，若视觉疑惑优先增加明确图形提示，不能暗改可部署范围。

Tidecross 原型第二稿更接近概念图 A 的水湾和多个层叠陆架。径路叠加检查发现：上路 y1 的 x4.3–6.7 段跨浅湾；下路 y5 的 x2.3–4 段跨浅湾；两路右侧共享 y4 的 x7.5–11 部分穿过浅水。UI Agent 已收到坐标建议，可按真实路径画短木板桥表现。路径切换只改变模型本来选择的路线；桥只在相应活跃路线段上绘制，且不改变实际碰撞或移动速度。入口与灯塔依真实 `game.path()` 的起终点落位，避免同生成图中静态烟柱/装饰混淆。

## 资产路径和锚点

- `assets/environment/{tidecross_background,twintide_background,echoreef_background}.png` — 1585×992 RGB。
- `assets/environment/portal.png` — 392×358 RGBA，底部约352，入口中心靠底；可按长宽比缩放。
- `assets/environment/lighthouse.png` — 202×392 RGBA，底部约387，需保留纵向比例。
- `assets/environment/deployment_pad.png` — 264×191 RGBA，顶部椭圆中心约 `(132,84)`。实际绘制宽66–72px，锚点在上平面中心，不依据图片宽高改变格子逻辑。
- `assets/items/chest_closed.png`, `chest_open.png` — 同为 512×512 RGBA，名义共同底锚 y492，alpha>8 实际底端相差 1px（490/491）。原图两姿态宽度 649/662 同比例缩小到422/430，箱体宽度差2%以内；使用固定 draw rect，不按各帧边界动态缩放。允许先结算真实抽取再播放视觉，不能拖延造成经济状态不一致。
- `assets/items/relics/{power,rapid,range,chain,freeze,blast,focus,relay}.png` — 128×128 RGBA，所有中心对齐，原始图形等比，局内建议 28–44px 呈现。名称/等级由引擎独立渲染。

## 验收

已对 16 个成品 PNG 实际解码检查，3 背景 RGB、13 个道具 RGBA，alpha 有真正透明外缘、非空不透明物体，半透明过渡保留，无阈值>8的 alpha bbox 提前裁断。所有目标文件有独立 SHA-256 值、尺寸、字节数及 alpha bbox（`docs/environment-asset-hashes.json`）。已在暖象牙背景合成检查闭/开箱透边、桥头入口、灯塔、石座、八个遗物图标：轮廓独立，颜色与材质一致，无假背景或黑底。初稿和改进稿的图像检查完成；实际整屏玩法验收由独立 UI/QA 负责，不以静态预览声称一比一实机验收通过。剩余重点：桥-路线一致性、靠边石座可辨识、上下光影和角色比例，以及右侧箱体开闭状态在 960×600 时可读。
