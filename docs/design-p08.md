# P08 玩法深度候选：潮雾传递（Shatter Tide）

状态：仅在隔离候选上评估，最后是否接纳以独立实测和真实操作验收决定。本轮以 P07 完整版本为基线，不更改地图、敌压、生命/金币、随机池、角色基值、R2/R3、战斗速度、风险奖励。P07 权威 Run.gd SHA256 `55f266962887b78956bc80542594ec337fe533d62c4deeee5b725888653dbf6e`。

## 1. 问题与体验假设

P07 已具备角色随机性、核心、位置与合成决策，30个种子×策略实际模拟验证布局重要，但核心多为通用数值增益；玩家即使拿到专项遗物也常继续按射程集中。本轮不靠加伤、加稀有度、免费选择或降低关卡压力来制造“新增玩法”，只探索一个会改变合成/部署选择的遗物效果。

体验：如果随机取得 Deep Frost（深潮雾/深霜）遗物，玩家考虑保留一名潮雾织师与礁锤、使攻击范围和出手覆盖相互配合；早期继续利用原本阵容，不要求强追指定组合。若当前只对付 Boss 或需要集中控制，遗物原有作用仍然成立，玩家无需被迫转构筑。

**MDA 假设**：随机发现角色/遗物 → 主动围绕其联动保留特定角色并调整站位 → 对群体控制状态产生不同分布 → 通过真实命中、路径效果及简洁反馈感知构筑选择。如果实际战斗无有效收益，或者普遍削弱原有 Deep Frost，取消候选而不是硬发布。

## 2. 机制契约（设计、反方与主审冻结）

保留 P07 Deep Frost 所有原效果（每阶全队伤害+3%，潮雾减速时间/强度）；保留现有基础 shatter（礁锤击中已减速主目标时扩大溅射及伤害）和 conductive（铜鸣对慢目标增伤）。唯一扩展：持有 Deep Frost 时，礁锤对符合条件的主目标攻击，能够在现有实际溅射伤害后重新分配减速时间。

1. 仅当本次真实礁锤直接攻击前，主目标存在当前减速且为非Boss、Deep Frost等级 L≥1，才具备资格。记录此刻剩余减速时间 s（已按本tick移动/衰减）。原 shatter 判断与伤害仍使用原有 marked 值。
2. 正常单击/溅射伤害按原规则执行；主目标若已死亡则不发生任何传递，Boss永不能作为源；次级只限该次实际受到溅射的、仍然存活、非Boss、当前未减速的敌人，不搜索范围外、未命中或已死者。
3. 对符合资格的次级按剩余路程升序、再按出生 ID 升序排序；取最多 L 个（冻结上限1/2）。若实际 n=0，不改变任何状态、不触发表现。否则每个获得 `s×0.5/n` 秒 slow，主目标减少实际新增时长总和 s×0.5。目标原本无减速，所以新增与扣除时长精确相等。
4. 同一实际攻击仅做一次传递；不是新的伤害或攻击事件，不再次遍历/递归触发。之后的真实攻击按原塔数组顺序读取更新后的 slow 状态；若后续另有实际礁锤攻击，可以再次按同一契约判断，这是新的权威攻击，不是递归。
5. 表现层独立事件 `game.tide_transfers`：`{from,to,duration,tick,tower_id,donor_id,recipient_id}`。每个实际追加对应一个事件，保留10tick以下（生命周期与伤害无关，重开/起波清空）。不可重复计为伤害、产生第二次命中或重复声音；UI可在攻击路径上显示淡青色状态传递/短注释，揭示的是实际事件而非虚构提示。截图、动效不能替代真实机制验收。
6. Tooltip 用简短语言明确：“礁锤击中的存活慢速目标把一半剩余减速平分给最多 L 个未减速的存活溅射敌人。首领不参与。源仍减速，但持续时间缩短。”如果拥有 Deep Frost 而没有匹配阵容，原数值仍有用，不能把该额外能力宣传成无条件全队增强。主目标与次级都已减速、主目标很快死亡、有/无Boss等情况不生效。

**例**：已衰减后主目标慢速剩 s=2 秒，R1有一个新目标时各1秒；R2有两个新目标时主1秒、次各0.5秒，只有一个合格目标时仍给1秒（等级不会把唯一受众的时长无故减半）。不能给已减速者再次刷新，不能从死亡单位获得免费状态，无产生新慢速预算。不同敌人的速度和既有控制抗性导致实际行程影响并非简单时间守恒；因此Boss源/目标明确排除，其他敌速依现有规则。相同时间预算分布可便于更多敌人触发 conductive/shatter，也可能使原本必须维持的前排加速；这正是定位、角色占位和实际攻击节奏的取舍。

## 3. 可反证验收

候选进入版本至少应满足：

- 纯机制：Deep Frost=0、未减速主目标、主/次死亡、Boss、无合格次级、已减速溅射中均保持 P07 行为；实际命中资质、次选排序、每次攻击只扣一次、≤L对象、R2唯一目标不降级、总时长守恒且未产生额外伤害；不同显示帧率、视觉显隐、暂停和倍速不影响同输入战斗。遗漏条件或递归风险即阻断。
- 玩家信息：不需要读长文即可知道为何考虑 Frost + Burst；燃烧/闪光等表现必须源于真实 `tide_transfers`，明确源损失一半剩余时间，不写“额外冻结全部敌人”。
- 真实随机策略：使用不少于30固定种子及真实购买，配对原 P07 与候选。至少比较通用（优先实际路线覆盖、低持有超过5时合成）和专项（已有 Freeze 且同时有 Frost/Burst 时优先部署两者、使礁锤覆盖与织师重叠、织师先部署）。四类风险开关×策略分别对照，不把既有先出手协同归因新增机制。
- **提前规定采用条件**：应有实际角色/遗物组合下可观察传递，且至少三个不同种子的同资产波次体现更少漏怪或保住风险奖励/避免失败；若只有事件日志而无战局受益证据，定位为探索性未达发布门槛。若任一正常策略60种子净损超过2个胜局、有效组合明显偏负向或出现早期合法资产死局，不采用该候选。该阈值是本轮代理模型门槛，不是人类获胜率目标；小样本不能宣称统计显著。没有转移事件的完整局，非表现状态必须和原版完全一致。
- 回归 70/30 当前资格、满池/首两角色保护、6币单次探索、售卖/合成、无负余额、波奖励与Boss条件。新增遗物描述不得改变原遗物ID、等级或随机权重，避免旧可复现输入失去意义。

## 4. 试验与结果

脚本 `scripts/model_design_p08.py` 从 P07 与候选各复制一份实际 Godot权威源文件到临时工程（不改产线），固定60种子437–496，每个种子两种布阵与风险开/关两个分支，两版本共480局。角色、遗物均真实花金币抽取。特化策略不在未抽到该遗物时虚构资源；即使同seed，后续胜负/风险奖励可能改变下波预算，故锁定“同波、同付费阵容与位置、金币、遗物、HP”的配对再比较漏怪等结果。控制传递次数按 event.tick 与当前权威 tick 相等统计，事件保留期间不重复计数。
