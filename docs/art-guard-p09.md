# P09 护送怪（Shellguard）视觉/可读性整改与截图门禁

范围：P09 生产候选，保留用户确认 P05 航海手绘微缩角色、场景美术与 P08 可读性。仅调整真实护送事件的表现，不修改 Run、随机池、角色原图、伤害、护送条件或碰撞。目标是让玩家区分“护送可用状态”和“确实发生拦截的一击”，同时普通攻击、冰霜/导电/碎冰、潮雾传递、血量与核心告急仍可读。遵循 DESIGN.md、sequence-animation-standard.md、vfx-design-standard.md、battlefield-atmosphere-standard.md。

## 一、P09 规则与可观察语义

实际 Run API：`guard_ready(e)`、`guard_remaining_ticks(e)`，以及 `guard_intercepts` 中每次真正拦截的记录 `{tick,tower_id,intended_id,guard_id,from,to,attacker_pos,damage,ready_tick}`。当前模型护送半径1.2格、冷却24tick（1.2s），仅满足模型全部条件时拦截 Brass/Mist 的直击；Hammer AoE、连锁次级攻击不属于拦截。伤害真实接收者由 Run 决定，原 `shots.to` 指向真正的 Shellguard，不为目标转移另外创建伤害。

**不要误解**：小盾图标仅表达“该护送怪的冷却可用/未恢复”，不是一条假预警，不证明某个旁边敌必然受保护，也不显示虚构防御半径、免伤或额外命中。

## 二、实际实现（BattleAtmosphere.gd）

| 层/状态 | 实际数据与图形 | 寿命和清理 |
|---|---|---|
| 可用护送 | 当前存活非Boss guard 且真实 guard_ready=true，小奶白盾框/青色勾 | 条件不再满足、敌死、phase!=fight立即消失或转等待态 |
| 等待护送 | 真实剩余tick>0，墨灰盾框内部圆形剩余冷却；总时长取 Run 脚本常量，不从视觉倒计时推断是否可用 | 随权威 tick 下降；到确切 ready tick 才切勾状态 |
| 已拦截击 | 实际记录年龄0–9tick，《from》为原意图对象真实位置、《to》为接收伤害的护送怪真实位置，保留快照。两点细虚线+小方向符号，仅说明转移关系 | 0.5s内逐tick淡出；未来/过期/重复事件不生成第二次显示 |
| 力场响应 | 在实际护送怪受击点，从真实 attacker_pos 方向绘制小黄铜盾弧与内侧奶白短闪，形状/质地明显区别潮雾青色水纹和原始攻击冲击；不再在原意图目标补画击中圆环 | 实际事件年龄0–9tick，短高亮仅前5tick；死亡可保留历史事件位置而不画死者的盾状态 |

护送指示装饰不显示攻击范围或虚构可反应窗口。不使用重复大字 INTERCEPT 浮签覆盖战场，规则/数量信息另由 Main 右栏提供准确文字与 tooltip。轮廓和状态形状不同，而不仅是颜色变化。

### 与 P08 密集可读性结合

- 新 `guard_status_records(game, visual_layout)` 是只读布局；只返回实际存活护送状态，未启用功能/旧模型不存在 API 时返回空列表。
- 每个微盾以该 id 的 P08 表现脚锚为基准，逐候选选择局部不遮挡 HP 条、兜底圆点和实际 CORE ALERT 框的16×16布局，过密才尝试12×12。候选距自身脚锚严格<43px，避免与其它角色名义轮廓重合（以尽量少遮挡为目标，不编造新的世界实体）；不同护送怪的实际徽记不相交。
- 已记录实际核心警告附近4个旧候选失败，增加局部旁侧/略下方位置并保留边界/关键警告约束，实际样本后0隐藏。若未来极端数据仍无法合法布置，小徽记宁可不画也不遮挡血量或告急；右栏真实可用数量仍保留，不把这一罕见情况描述为通过所有可能场景。
- 新 `guard_redirect_records(game)` 根据唯一 tick:tower:intended:guard 去重复，不用当前敌人坐标或 P08 render offset 重定位历史命中，不创造 status/damage/trace。旧 P08/未启用候选没有此列表时返回空。命中、历史痕迹和音频仍用真实原事件；helper 不调用音频或伤害函数。
- Main 已消除实验版重复 `draw_guard_escort`、`draw_guard_intercepts` 方法，实际顺序：角色/死亡 → draw_combat（一次普通真实伤害/联动、潮雾传递与护送表现）→ draw_guard_status（一次状态）→ P08真实HP条 → CORE ALERT；没有重复画第二条假攻击。新版 SCREEN/CLUSTER/FRONT 指令不由美术猜测，真实射击使用 Run 新选择结果。
